# 2026-10-20 · 2.4.5(i) 提审被拒的返工（保存位置改「用户选一次 + 书签」）

## 触发

App Review 拒了 1.0 build 2（Submission `e899accb-3903-4d45-b4da-c83a2aca3356`，
2026-10-14，MacBook Pro 14"），同一条 Guideline 2.4.5(i) 两条：

1. `com.apple.security.assets.pictures.read-write` —— "does not have matching functionality"；
2. "uses or offers to use **pre-set locations**, including `~/Pictures`" —— 要求用标准
   Open/Save 面板让用户选默认位置。

根因只有一个：为了「⌘S 默认有个地方能存」，预置了 `~/Pictures/Marquee` 并为它声明 Pictures entitlement。

- `App/Marquee.entitlements`：删 `assets.pictures.read-write`，只剩 `app-sandbox` +
  `files.user-selected.read-write`。
- `OutputSettings.directory` → **`URL?`**；`defaultOutputDirectory()` 改名
  `savePanelStartDirectory()`（只剩面板起点：存在则 Marquee → Pictures → 家目录）。
- 新增 `OutputSettings.securityScopedBookmark(for:)` / `resolveDirectoryBookmark(_:)`。
- `UserDefaultsOutputStore`：`bookmarkKey` + `chosenDirectory()`（**有书签只认书签**，
  解析失败=没选过；无书签才退回路径）+ `saveDirectory(_:bookmark:)`。
- `ScreenshotArchiver.write`：**没有目录就失败并说清原因**，不再兜默认路径；
  写盘用 `startAccessingSecurityScopedResource()` / `stop` 包住。

- 偏好页「保存位置」没选过显示 `未选择 · 第一次保存时选`；「选择…」同时存书签。
- 新文案 2 条（catalog 最小插入 20 行 + `translations.py`）。
- 文档：PITFALLS **202**、MAS-AND-MONETIZATION **§2.6**、APP-STORE-LISTING 审核备注、

## 上传被拒：App sandbox not enabled（同日，第二次打回）

- 现象：ASC 报 `com.tango.marquee.pkg/Payload/Marquee.app/Contents/MacOS/Marquee`
  缺 `com.apple.security.app-sandbox`。
- 真因：Xcode Organizer 归档时选的是 **`Marquee`** scheme，而它的 Archive 配置是
  `Release`（Developer ID 那条路，刻意无沙盒）。今天的归档
  （`~/Library/Developer/Xcode/Archives/2026-10-20/…21.43.xcarchive`）
  entitlement 打出来是 **空字典**，且版本停在 `0.1.0 (1)`。
  ⇒ 归档产物本身没问题，是**选错了配置**；本地没有任何一道检查会说话。
- 修：
  1. `project.yml` **两个 scheme 的 Archive 都改成 `MAS`**；Developer ID 的 DMG 只走
     `package.sh`（显式 `-configuration Release`，不读 scheme）。
  2. `MARKETING_VERSION: 1.0` / `CURRENT_PROJECT_VERSION: 3`（被拒的是 1.0 (2)）。
  3. `package-mas.sh` 预检新增第 ④ 条：`pkgutil --expand-full` 拆开**即将上传的 .pkg**，
     核载荷里的 executable —— Apple 验的是它，不是导出目录里的 `.app`。
- 验证：用 `-scheme Marquee`（就是出错那条 scheme）重新 archive →
  版本 `1.0 (3)`、entitlement 正好两项（app-sandbox + user-selected），无 Pictures。
  ⚠️ 直接裸 `xcodebuild` 归档要自己补 `OTHER_SWIFT_FLAGS=-disable-sandbox`
  （`MARQUEE_DISABLE_COMPILER_SANDBOX` 只有 `build.sh`/`package-mas.sh` 会读）。
- 文档：PITFALLS **204**、CONNECT §6.6、验收 **AA9**。
