# 2026-11-02 · 付费形态重估：每项 Pro 能力 3 天体验

分支 `feat/monetization-shape`（从 `main` 切出）。

## 起因

app 已上架。用户反馈两点：

1. App Store 商品页第一眼就是 `Marquee Pro ¥36.00`，看不出「可以免费下载」；
2. 下载后一碰 Pro 功能就弹要钱的卡片 —— 「想要更多 → 体验 → 买断」这条链里，**体验那一环是空的**。

## 定案

| 项 | 决定 |
| --- | --- |
| 商品结构 | **不动**：仍是一个 ¥36 非消耗型。不拆开卖 ⇒ `Entitlement` 不用引入「能力集合」，约 1600 行既有测试不动 |
| 免费边界 | **不动**：6 类能力全开 |
| 新增 | 每项 Pro 能力**各自 3 天**体验窗口，从该项第一次被使用那一刻算 |
| 体验粒度 | 用户选的是「按天数、不按次」+「每项独立计数」 |
| 排除项 | 「最近截图不限量」**不参与**体验 —— 它不是入口，是数量上限，用户截到第 6 张时感知不到「体验开始了」 |
| 记账条件 | **只给 `.neverPurchased` 记**（`EntitlementSnapshot.canStartFeatureTrial`） |

## 落地

4 张票（`.scratch/issues/2026-11-02-feature-trial/`）：账本与判据 / 钉图端到端 / 另两个入口 / 商店页文案。

代码：

- 新 `Modules/Sources/MarqueeCore/FeatureTrial.swift` —— `FeatureTrialPolicy`（默认 3 天，夹到 ≥1）· `FeatureTrialState` · `FeatureTrialLedger` · `FeatureTrialStoring` + UserDefaults / 内存两个实现
- `Entitlement.swift` —— `BlockedReason.featureTrialEnded` · `ProFeature.supportsFeatureTrial` · `EntitlementSnapshot` 加 `featureTrials` + `evaluatedAt` · `access(to:)` 改成按项判 · `canStartFeatureTrial`
- `ProCard.swift` —— 判据从 `snapshot.blockedReason` 换成 `access(to:feature).blockedReason`；`.featureTrialEnded` 与 `.neverPurchased` 共用按钮规则
- `ProCardRenderer.swift` —— `title(_ content:)` 在体验到期那一档换成「XX 的 3 天体验已结束」（4 句独立文案，不拼接）
- `ProEntitlement.swift` —— 持账本，`markFeatureTrialStarted` 是**全 app 唯一写点**
- `SelectionOverlayController` / `CaptureCoordinator` —— 三个入口接同一个判据与写点

## 两个必须记住的判据

1. **`.notStarted` 只对 `.neverPurchased` 放行。** 撤销（退款/被移出家人共享）的人也有一份空账本 —— 一律放行等于**退款用户永久免费**。变异验证时删掉这个限定，4 条测试同时变红。
2. **`evaluatedAt` 不参与 `EntitlementSnapshot` 的相等性。** 算进去会让「判定没变就不通知」的守卫失效，界面被无意义重绘。是 `EntitlementCoordinatorTests` 抓出来的。

## 环境问题（本机）

- **签名证书不在本机**：`UKXWZ3FS84` 的开发证书没有 ⇒ `./scripts/build.sh` 必然失败在 `No signing certificate "Mac Development"`。编译检查走 `xcodebuild ... CODE_SIGNING_ALLOWED=NO CODE_SIGNING_REQUIRED=NO`。
- 补了一次性设置 `defaults write com.apple.dt.Xcode IDEPackageSupportDisableManifestSandbox -bool YES`（`docs/DEV-NOTES.md` §4 要求的）。
- **`SandboxTests` 的「记住的是用户选的那一个目录」在本机恒红**，已在 `main` 上复现 —— 与本次改动无关。原因是这台机器上非沙盒测试进程建不出 security-scoped bookmark，`saveDirectory` 没生效。**没有修**（改测试要单独确认）。
