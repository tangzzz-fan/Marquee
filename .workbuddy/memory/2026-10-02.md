### 新踩到的三条（已写进 PITFALLS 89–92）

1. AppKit 的绘制顺序是「自己的 `draw` → 子视图」，**子视图永远盖在父视图自己画的东西之上**。
   想给自绘区域换材质背景，必须把内容挪到与背景**并列**的兄弟层，不能挂在背景下面。
2. `NSVisualEffectView` / `NSGlassEffectView` **默认参与命中测试**，会吃掉鼠标事件
   （表现与「入口没接线」一样）。要包一层 `hitTest == nil` 的容器。
3. 悬浮面板必须 `.behindWindow`：`.withinWindow` 会拿**变暗蒙层**当素材，糊出来还是一片纯色。

### 探针实测的结论（勿靠记忆）

`String.LocalizationValue` 的插值说明符按类型定：
`Int`/`Int64`/`count` → `%lld`；`Int32`/`OSStatus` → `%d`；`UInt32`/`UInt8` → `%u`；
`String` → `%@`；`Double`/`CGFloat` → `%lf`；`Float` → `%f`。
探针（`/tmp/l10nprobe`）顺带证明整条链路是通的：`xcstringstool compile` 出的
`en.lproj` 放进自造 bundle 后 `String(localized:bundle:)` 确实查得到。

### 踩到的坑（已进 PITFALLS 93–97）

1. 插值文案**不能先拼后查**（`L10n.t("已复制 " + text)` 永远匹配不上，静默回落中文）。
2. 自己写源码扫描器时，多行字面量里的**行继续**（`\` 结尾换行）也是换行 ——
   漏计一次，后面所有报错行号整体前移，诊断全部变成误导。
3. 扫描器收集 key 那一趟**不能看行标记**：`logger.info("…\(L10n.t("…"))")` 里的 key 是算数的，
   跟着跳过会把它变成"孤儿"然后误报。
4. 扫描器必须自带**自检**，否则"什么都扫不到"会让所有断言全绿。
