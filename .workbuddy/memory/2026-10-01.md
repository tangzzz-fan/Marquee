## 追加：命中被挡住的窗 + Esc 要按多次

**用户反馈**：停住时会把区域内看不见的窗口也选上；Esc 要按好几次才退出。

- 命中以前按 `windowLayer` 重排，同层又沿用 SCK 不稳定的数组顺序，框相交就会选中已经被挡住的窗。改为 `CGWindowListCopyWindowInfo` 的前台→后台，并丢掉不在屏上的、补上 alpha（全透明挡板不再可点）。

## 追加：ticket 11 滚动截屏（手动滚动）

菜单栏加「滚动截屏」（6 项，到 PRD 上限）。进入后拖区域或点窗口＝**立刻开抓**，`⏎` 结束、`⌘S` 结束并落盘、`Esc` 取消。抓帧期间面板 `ignoresMouseEvents = true` 让滚轮穿透（否则滚不动）。

| 落点 | 内容 |
| --- | --- |
| Core | `ScrollRegistration`（接缝 `ScrollFrameRegistering` + 阈值策略）、`ScrollStitcher`（增量累计 + 亚像素相位）、`ScrollStitchRenderer`、`ScrollCaptureSession`（被逐帧驱动的会话） |
| Capture | `VisionScrollRegistrar`（`VNTranslationalImageRegistrationRequest`） |
| Overlay/App | 覆盖层长截图模式（HUD 三行 + 鼠标穿透 + 驱动任务）、菜单项、`CaptureCoordinator` 接线 |
| 测试 | 新增 `MarqueeCaptureTests`（真实 Vision 装置自检）+ `MarqueeTestSupport`（合成长页/位图/MAE）；Core 侧补拼接与状态机单测。**165 + 6 = 171 全绿** |

**实测**：单次配准 8.3 ms（首次 68 ms 一次性）、5 帧拼接 1 ms、端到端 **MAE 0.0**（阈值 < 1/255）。

### 过程中发现并修掉的 2 个真实缺陷

1. **`AnnotationRasterizer` 把底图上下颠倒了**（ticket 07 的导出路径）。根因：先翻 CTM 再 `draw` —— 翻转后图像的顶行仍在 `rect.maxY`，而那已是视觉下边。**纯色底图看不出翻转**，所以原来的断言是空过的；已改用"上黑下白"的底图补回归。
2. **长图底边留半透明横线**：每片底边用 `ceil` 会多算一行"只覆盖一半"的行，谁都不完整覆盖它。总高与底边都改 `floor`。

## 追加：长截图连按 ⏎ 的竞态

用户问"滚动截图怎么操作"时顺手核代码发现的：`isScrollCapturing` 要等 `session.begin()`
返回才为真，而 `begin` 里要走权限门 + 抓基线帧（几十到上百毫秒）。这段窗口内连按 `⏎`
会再进一次 `beginScrollCapture`，`scrollSession` 被覆盖，**前一个会话失去引用但抓帧循环照跑**。

改用 `hasScrollSession`（会话是否已建立）当闸门；`performCommit` 在"已建立但没起好"时
**忽略按键**而不是调 `finish()`（那时会因一帧都没有而报"没有采到任何画面"）。
提交 `91d3f8d`。

## 追加：长截图看不出蒙层 + ⌘Tab 后高亮指错窗口（用户报的两个问题）

1. **"长截图怎么拖区域"的真正原因**：空状态把**整块屏**当高亮镂空 → 镂空等于不挖洞 →
   屏幕几乎不变暗，用户看不出覆盖层在工作。提示文字还挂在屏幕角上。
   改成满屏蒙层 + **光标旁**挂提示框（`hintAnchor` / `hintText`）。
   ⚠️ 教训：**`fillMask(punching:)` 的洞有多大，蒙层就少多少；洞等于整屏时这个分支等于没画。**
2. **⌘Tab 后高亮指错窗口**：`cachedWindows` 只在 `present()` 取一次，应用切换后不刷新，
   而命中顺序依赖前台→后台；且 `updateHover` 只在鼠标移动时调用。
   改为 observe `NSWorkspace.didActivateApplicationNotification` → 重取清单 + 强制重算悬停。
   **刻意不动落点**（已锁定的窗口是明确意图；`desktopIndependentWindow` 被挡也截得到）。
3. 附带：覆盖层 `keyDown` 的 default 分支原来对任何未映射键都 beep，⌘Tab/⌘`/⌘Space
   这类系统组合应当放行给 `super`。否则用户按 ⌘Tab 得到的是"叮"一下什么都不发生。

提交 `797e291`。新增 `-marqueeSmokeScrollOverlay`（长截图空状态的绘制分支，免权限可冒烟）；
