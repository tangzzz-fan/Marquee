# Marquee · 窗口类三块 · 出稿 brief

> 交给 open-design（`marquee` 项目）。这一轮出**三块**：偏好设置（4 页）、最近截图面板、菜单栏下拉。
>
> 输入口径同上一轮：**只给逻辑，不给当前 UI 实现**（不带窗口尺寸、字号、颜色值、控件类型、布局）。
> 完整清单见仓库 `docs/design/PAGE-LOGIC.md` §C / §D / §E。

---

## 0. 先说这一轮与前几轮的**根本差别**

前几轮出的都是**"独自占满屏幕、几秒钟就走"**的界面（覆盖层、引导页、升级卡片、原地教学）。

**这三块不是。** 它们是**常规窗口**，会与用户其它应用并排存在、会**长时间停留**
（偏好设置可能被开着对照着改，最近截图面板会被反复叫出来）。

⇒ 两条后果：

1. **要用普通窗口的深浅两套**（与引导页、升级卡片同源），**不是**覆盖层那套"永远深色"。
2. **它们的信息节奏是"读"**，不是"扫一眼就走"。表格、分组、对齐在这一轮是主角。

⚠️ 项目里已有四份稿：`first-run-onboarding.html`、`pro-upgrade-card.html`、
`first-use-coach.html`、`capture-overlay.html`。
**请先读它们的「01 共用语言」并沿用** —— 尤其引导页与升级卡片那两套**普通窗口的深浅材质**，
这一轮要用同一套。

⚠️ **一处已知的跨文件不一致**（上一轮发现、当时没动）：`pro-upgrade-card.html` 的尺寸表里
还写着「录制框 220 × 34 pt」「键帽 22 高」，但引导页改成 Alfred 式之后实际是
**400 × 40 / 24**。**以引导页那份为准**。本轮若引用到，请按新值。

# C. 偏好设置（**正好 4 页**）

## C.0 跨四页的四条共同逻辑

1. **没有「确定 / 应用」按钮。** 改一下**立刻生效、立刻落盘**。
   这类工具的偏好项都是一眼能看出效果的小开关，而"改完忘了点应用"是这类窗口最经典的坑。
2. **正好 4 页。** 多一页的收益远小于破坏一条写进产品文档的约束。
   （所以后来加的 Pro 状态区是**接在「通用」页底部**，而不是新增第 5 页。）
3. **每一项都要有一句说明"它到底改变什么"。** 这一页上每一项都直接改变用户看到的结果，
   "改了但没生效"必须是**不可能**的。
4. **四页的信息量本来就不均**（通用 2 项 + 状态区；输出 5 项）—— 这是刻意的问题，
   见文末提问 2。

## C.1 「通用」页

| 项 | 含义 | 默认 |
| --- | --- | --- |
| 截图后播放提示音 | 截成功时播一声系统音效 | **开**（关掉的实际场景是"连着截很多张时不想被打断"） |
| 开机时自动启动 | Marquee 常驻菜单栏，开机就有 | **关** |
| **Pro 状态区**（底部） | 当前权益状态 + 「升级到 Pro」+「恢复购买」 | —— |

**开机自启动有一条必须被表达的逻辑**：注册到系统登录项**可能失败**。
失败时界面必须**把开关拨回去**，并给出原因与**去哪看**
（「系统设置 → 通用 → 登录项」）—— 否则界面显示"已开启"而系统里没有，用户只能靠重启去发现。

**Pro 状态区**（六种状态文字，都由权益判定整句推出，界面不许自己拼）：

| 状态 | 文字大意 |
| --- | --- |
| 还在确认 | 正在确认… |
| 免费版 | 免费版（最近截图保留 N 张） |
| 试用中 | 试用中，还剩 N 天 |
| 已购买 | 已购买，谢谢 |
| 被撤销 | 这笔购买已被撤销 |
| 找不到 | 这个账号下找不到这笔购买 |

两个按钮：**升级到 Pro**（已购买时变成「已购买」并置灰）、**恢复购买**（**永远可点** ——
App 审核要求可恢复，而且"我明明买过"的人第一件事就是找它）。
**恢复购买的结果必须如实回报**：恢复了 / 这个账号下没有可恢复的 / 失败了。
这是用户主动点的动作，**悄悄失败等于骗他**。

## C.2 「截屏」页

| 项 | 含义 | 默认 | 备注 |
| --- | --- | --- | --- |
| 截图里包含鼠标指针 | 截图是否把光标画进去 | **关** | 指针会挡在内容上 |
| 窗口截图带阴影 | 截某个窗口时带系统阴影 | **开** | 在覆盖层里按 `⌥` 可以**临时反转**这一项 |
| 延时截图 | 按快捷键后等几秒再出现覆盖层 | **不延时** | 档位：不延时 / 3 / 5 / 10 秒 |

**延时为什么是"覆盖层出现**之前**"那几秒** —— 覆盖层一旦出现就吃掉所有鼠标事件，
那时候再等几秒，用户反而什么都摆不了。这一条会决定说明文字怎么写。

## C.3 「输出」页

| 项 | 含义 | 默认 | 备注 |
| --- | --- | --- | --- |
| 保存位置 | 图存到哪个文件夹 | `~/Pictures/Marquee` | 旁边有「选择…」打开系统的选文件夹面板 |
| 图片格式 | PNG（无损）/ JPEG / HEIC | PNG | 后两者有损 |
| 质量 | 有损格式的压缩质量 | —— | **只在有损格式下有效 —— 这一条的「无效」状态要看得出来** |
| 文件名模板 | 例如 `Marquee-{date}-{n}` | 有默认值 | 旁边要给变量提示 |
| 可用变量 | `{date} {time} {n} {app} {title}` | —— | 常驻提示，因为没人记得住变量名 |

**必须说明的一条**：**只有按 `⌘S` 或点「保存」时才写盘。**
也就是说"保存位置"这个设置**与日常截图无关** —— 不说明的话，
用户会以为每截一张就往那儿存一份。

## C.4 「快捷键」页

只有一件事：**全屏截图的全局快捷键**。

- 一个录制控件：点一下 → 显示"按下新的组合…" → 用户按什么就录什么
- 显示**当前**生效的组合
- **冲突要明确告知**，并把显示**回滚**到原来那个（然后用户可以立刻再试）—— 用醒目色
- 一个「恢复默认」按钮
- 一句说明：全局生效（应用不在前台也能触发）

## C.5 交付（偏好设置）

四页并排 + 每页的**状态**：开关开/关 · 延时档位 · 有损/无损下质量行的两种样子 ·
录制中 / 冲突红字 / 已生效 三种反馈 · Pro 状态区的六种文字 + 两个按钮的可用/置灰 ·
开机自启失败时的回滚 + 那条说明。全部含尺寸标注。

# D. 最近截图面板

**为什么是弹层而不是一个"图库窗口"**：要解决的是"**刚**截的图找不到了"。
独立图库窗口会带来窗口管理、搜索、分组、拖拽导出 —— 那是另一个产品。

- 从菜单栏弹出，**点别处自己收起**
- 最多列 **12 条**（再多性能与"看得过来"两方面都不划算）
- 每条一行：**缩略图** + **时间**（如 `10月3日 18:47`）+ **尺寸** `1234×768 px`
  （有标注时追加 `· 3 个标注`）+ `[编辑]` `[删除]`
- **缩略图本身就是"复制到剪贴板"按钮** —— 点图就该拿到图，这是最自然的那一下
- 空态：一句话 + 告诉用户按什么键能截第一张
- **免费版底部一行小字**：「免费版只保留最近 N 张 · 升级到 Pro 可保留全部」
  ⚠️ **这里刻意只放一行字、不弹卡片** —— 截图是高频动作，每截一张弹一次"要不要升级"等于自杀

**两条必须清楚的动作语义**：

| 动作 | 语义 |
| --- | --- |
| **编辑** | 用历史里的**原图 + 标注**重开编辑器 —— 原有的标注**仍然可编辑**，不是在成品图上再画 |
| **删除** | 从历史里删掉，**连磁盘上的文件一起清** |

**交付**：列表常态（多条）· 空态 · 免费版配额小字 · 悬停/按下态 · 缩略图即按钮这件事要看得出来。含尺寸标注。

# E. 菜单栏下拉菜单

**约束：≤ 6 项。当前 5 项 + 一条分隔线。**

```
截屏            （显示当前快捷键）
滚动截屏        （免费版带小锁，但**可点**）
最近截图
设置…            （⌘,）
──────────
退出 Marquee     （⌘Q）
```

**逻辑要点**：

1. **「滚动截屏」在免费版带一把小锁，但绝不置灰。** 置灰了用户点不动，
   就永远看不到那张解释为什么的卡片。**只换图标，不动可用性。**
2. **「最近截图」不是子菜单。** 子菜单放不下缩略图，而"看不见缩略图"
   就等于回到"我记不清哪张是哪张"。
3. **菜单项旁边的快捷键是"告知"，不是"触发"。** 全局触发由系统级热键负责，
   菜单里显示它纯粹是告诉用户现在是哪个键。
4. **未实现的项直接不出现**，不要放一个点了没反应的假入口。

**交付**：菜单展开态（免费版带锁 / 已购买不带锁 两种）· 分隔线与快捷键列的对齐 · 含尺寸标注。

# F. 硬约束（三块共用）

- 偏好设置**正好 4 页**；菜单栏下拉**≤ 6 项**
- **不许设计需要新窗口 / 新弹窗 / 新步骤的方案**
- 深浅两套（普通窗口，与引导页/升级卡片同源）
- 这三块的节奏是"**读**"，不是"扫一眼就走" —— 排版与对齐在这一轮比动效重要
