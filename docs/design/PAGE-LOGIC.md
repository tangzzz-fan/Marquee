## 0. 先把产品说清楚

**Marquee 是 macOS 截图 + 标注工具。它没有主界面。**

装完之后桌面上什么都没多出来 —— 只是菜单栏多了一个图标。用户与它的全部交互，
发生在**按下快捷键之后、屏幕被冻住的那几秒里**。

体验目标一句话：

> 按一下快捷键 → 屏幕冻住 → 框出要截的那块 → 就地标注 → 直接进剪贴板。

**"少一步"是它的核心价值。** 任何要求用户"先打开一个窗口"的设计都是反产品的。
这条判断优先于本文件里的任何其他条目。

## A. 覆盖层 —— 产品的主界面

### A.0 它是什么

一块盖住**全部屏幕**的半透明层。出现时屏幕内容被冻住，用户在上面框选、标注。
**它不是窗口**：没有标题栏、不进 Dock、不抢别的东西的焦点；它就是这一次截图的全部。

### A.1 三个阶段（必须都能被表达）

| 阶段 | 用户在哪 | 他看到什么 |
| --- | --- | --- |
| **① 空态** | 还没框任何东西 | 提示"拖出要截的区域 / 单击一个窗口"，随光标跟一句小提示 |
| **② 已落点** | 框选完了（或点了一个窗口） | 选区四周出现 8 个可拖的控制点；工具条出现；读数出现 |
| **③ 长截图进行中** | 正在往下滚着拼 | 读数换成进度与提示，选区描边加粗 |

三阶段**不是三个页面**，是同一块界面上的三种形态。切回上一阶段（取消选区、结束长截图）
都要能平滑回去。

### A.2 空态下能做的事（三条路，都要能一眼看出来）

1. **拖** → 框出一个矩形区域
2. **单击** → 高亮鼠标下的那个窗口；再按一次确认，就截那个窗口
3. **什么都不选直接确认** → 截整个屏幕

外加：`Esc` 取消这次截图。

> 空态的最大风险是**让人以为卡住了**。屏幕冻着、什么都没有，用户会怀疑是不是死机。
> 这一阶段的提示与光标形态，是本界面最重要的一件事。

### A.3 选区（②阶段）

- **8 个控制点**：四角 + 四边中点。拖动改大小。
- **框内拖动** = 移动整个选区；**框外** = 重新框一个。
- **最小尺寸 8 点**：再小就停住，不翻转。
- **`⇧` 锁比例**：以位移更大的那个轴为准。
- **方向键微调**：1 点；配合修饰键按更大步长。
- **吸附**：靠近屏幕边、窗口边时自动吸上去，并**画一条贯穿屏幕的细线**标出吸到了哪条边。
  （没有这条线，用户只会觉得"这里有点顿"，说不上来在吸什么。）
- **读数**：实时显示当前选区的**像素尺寸**与位置。

### A.4 工具条（15 格）

从左到右，分四组，组间有分隔：

```
[矩形][椭圆][表情][箭头][画笔][马赛克][文字]  │  [样式]  │  [识别文字]  │  [撤销][重做][保存][钉图][取消][完成]
      └────────── 7 个绘制工具 ──────────┘       样式         Pro          └────── 6 个动作 ──────┘
```

**逐格逻辑**：

| 格 | 类型 | 点下去做什么 |
| --- | --- | --- |
| 矩形 / 椭圆 / 箭头 / 画笔 | 工具（拖一笔成形） | 选中它，之后在选区里拖就画出对应形状 |
| 表情 | 工具（点一下落一个） | 选中它，**同时弹出表情面板**；点某个表情直接落下 |
| 马赛克 | 工具（拖一笔） | 选中它，拖出的区域被马赛克盖住 |
| 文字 | 工具（点一下放输入点） | 点一下出现输入框，敲完 `⏎` 落成标注 |
| **样式** | 弹层入口 | 展开「色板 ×6 + 尺寸 ×3」的弹层 |
| **识别文字** | 动作（**Pro**） | 识别选区里的文字并复制到剪贴板 |
| 撤销 / 重做 | 动作 | 就是撤销重做；没得撤销时置灰 |
| 保存 | 动作 | 落盘并结束（等同 `⌘S`） |
| **钉图** | 动作（**Pro**） | 把这张图钉在屏幕上，同时**照样进剪贴板** |
| 取消 | 动作 | 丢掉这次截图（**红色**） |
| 完成 | 动作 | 提交（**绿色**） |

**必须成立的三条**：

1. **取消红、完成绿。** 它们承担的是"一眼看出哪个是完成、哪个是取消"，
   而这两个动作一个不可逆、一个可逆 —— 用户的原话是"取消按钮使用红色，有对比度"。
   对比度要够（正文级），且**在压着任意屏幕内容时都够**。
2. **点亮只认"自己"。** 选中画笔 → 画笔亮；打开色板弹层 → **只有「样式」亮**。
   （曾经写错过：打开表情面板时「样式」也跟着亮，用户当即指出"不对"。）
3. **动作格没有"选中态"。** 撤销/保存/钉图这些点完就执行，给它们点亮会让人
   以为"现在处在撤销模式"。

**工具与动作的分界必须一眼可辨** —— 左边是"我用哪个工具"，右边是"我现在做什么"。

### A.5 两个弹层

| 弹层 | 何时出现 | 内容 |
| --- | --- | --- |
| **样式** | 点「样式」格 | **色板 6 色**（红 / 橙 / 黄 / 绿 / 蓝 / 白）+ **尺寸 3 档** |
| **表情** | 选中「表情」工具时自动出现 | 常用表情 24 枚（对错 / 指向 / 强调 / 完成度） |

**尺寸那 3 档的含义会随工具变**，这是这一块最容易被设计忽略的地方：

| 当前工具 | 三档代表 | 三档的值 |
| --- | --- | --- |
| 矩形 / 椭圆 / 箭头 / 画笔 | **线宽** | 2 / 4 / 8 点 |
| 马赛克 | **打码强度**（格子大小） | 4 / 8 / 16 点 |
| 文字 / 表情 | **字号** | 18 / 28 / 44 点 |

> 三档的**形状**也该跟着变：线宽画成大小不同的圆点、打码画成大小不同的方块、
> 字号写成一个大小不同的字母 `A`。**不许按数值线性映射** —— 4/8/16 线性画出来，
> 后两档几乎看不出区别。

弹层贴在工具条外侧；放不下就翻到内侧；最后必须夹进屏幕。
**关掉弹层的 `Esc` 不能丢任何东西**（选区、已画的标注一字不动）。

### A.6 放大镜取色（只在②之前）

`⌥` 悬停 → 光标旁出现一个放大镜 + 该像素的 **HEX / RGB** 值；点击即复制。
落点之后 `⌥` 改而表示"窗口截图不带阴影"。

> 同一个键在两个阶段做两件完全不同的事 —— 这是有意的（两件事都很顺手），
> 但界面上必须让用户能看出"现在这一下 `⌥` 是哪个意思"。

### A.7 文字输入

点「文字」工具 → 点一下 → 就地出现一个输入框，敲内容，`⏎` 结算成标注。

三条硬逻辑：

1. **必须用真的系统输入框**（中文输入法的候选窗/联想/光标全靠它，自绘等于自己实现一遍输入法）。
2. **编辑期间键盘整条让行**：只拦 `Esc`，其余按键（包括空格、方向键）都归输入框。
3. **「结算」≠「丢弃」**：点别处或按 `⏎` 是结算（内容落成标注），**只有 `Esc` 才丢**。

### A.8 长截图（③阶段）

用户拖出一块区域 → 往下滚 → 应用把每帧拼起来，越拼越长。

**读数要换成**：已拼高度（px）、已拼帧数、可选的一行配准耗时。
**提示行要给出当前能做的事**，且**随自动滚动开关而变**：

- 手动模式：`继续往下滚，或按空格自动滚 · ⏎ 结束 · ⌘S 结束并保存 · Esc 取消`
- 自动滚动中：`自动滚动中 · 空格停止 · Esc 停止（已拼的保留）· ⏎ 结束`

**告警**（非空时用醒目色）：`已经滚到底了` / `这一帧没对齐` 之类。

**自动滚动的两处前置**（这决定提示文案，不能混）：

| 情况 | 提示 |
| --- | --- |
| 这个构建**不支持**自动滚动（商店版沙盒限制） | 说明"这个版本不提供自动滚动"，**绝不许出现「辅助功能」四个字** |
| 支持但**没授权** | 告诉用户去「系统设置 → 隐私与安全性 → 辅助功能」勾一下 |

> 说反了就是把用户支去干一件注定没用的事。**沙盒优先于授权** —— 这个顺序是判据的一部分。

### A.9 会被挡住的能力（Pro）

免费版里「识别文字」「钉图」「滚动截屏」不能直接执行。规则是：

- **入口看得见、点得动**，点了**原地弹一张解释的小卡片**（见 J）。
- **不许**把入口藏起来或置灰 —— 置灰了用户点不动，就永远看不到那张解释为什么的卡片。
- **工具条上那两格要有一个常显的小锁标记**，让人在点之前就知道。
- **关掉卡片不许丢任何东西**：选区、已画的标注、输入到一半的文字，一字不动。
  卡片是最浅的一层，`Esc` 先收它。

### A.10 键盘（全部）

| 键 | 作用 | 什么时候 |
| --- | --- | --- |
| 方向键 | 微调选区 | 已落点 |
| `⇧` | 锁比例 | 拖控制点时 |
| `⌥` | 悬停取色 → 落点后＝无阴影 | 分阶段 |
| `空格` | 自动滚动开/关 | 只在长截图进行中 |
| `⏎` | 提交 / 结束长截图 | 全程 |
| `⌘S` | 结束并落盘 | 全程 |
| `⌘Z` / `⇧⌘Z` | 撤销 / 重做（编辑文字时归输入框） | 全程 |
| `Esc` | **四级退** —— 详见下 |

**`Esc` 是四级退，绝不一步把整次截图丢掉**：

```
① 弹层/卡片开着  → 只收它
② 正在输入文字    → 只丢这个输入，标注留着
③ 工具选中        → 只取消工具
④ 有选区          → 取消选区
（都没有）        → 才取消整次截图
```

> 这条顺序本身就是要设计的东西：用户需要感觉到"我这一下 `Esc` 退掉的是哪一层"。

⚠️ **`Esc` 与 `⏎` 在两个界面上共用同一条规则**（2026-10-03 定）：

```
Esc = 退最里面那一层；退无可退时朝「不丢东西」的方向退        ⏎ = 一步确认
```

两边的**层数不同**（覆盖层多了卡片 / 弹层 / 自动滚动几层，编辑器多了「选中的标注」一层），
**退到底朝哪个方向也不同**（覆盖层＝取消；编辑器＝完成并带走）。
这两处不同是**交互模型与"底"不同使然**；统一的是**规则**。

> 给设计方的提示：这条与 macOS 自己的约定同向（`Esc` 走取消按钮、`⏎` 走默认按钮）。
> 请把「**退掉的是哪一层**」**看得见** —— 用户需要知道这一下 `Esc` 收掉的是什么。
> 编辑器那张更完整的表在 **B.0**（两个出口并排画出来）。

### A.11 约束

- **整条工具条必须放得进 1024 点宽的屏。** 这是产品级硬约束，不是建议。
  （15 格就是为了这条从 12 格＋12 格色板改出来的。）

## B. 编辑器窗口

**什么时候进**：只有**长截图**结束后会进来。普通截图不经过它
（普通截图走"就地标注 → 直接进剪贴板"，不开窗口）。

**它比覆盖层多出什么**：裁剪、缩放平移、文字的两套预设（普通文字 / 序号）、
以及"重新打开历史里的某张图继续改"。

### B.0 键盘（`Esc` / `⏎` 与覆盖层**同一套**）

| 键 | 作用 |
| --- | --- |
| `Esc` | **退一层**：丢正在输入的文字 → 取消裁剪 → 退回「选择」工具 → 取消选中 → **完成并复制并关闭** |
| `⏎` | **一步直达**最后那件事（与工具栏那颗 `✓` 同一个动作）。裁剪进行中＝应用裁剪 |
| `⌘S` | 保存到磁盘并关闭 |
| `⌘Z` / `⇧⌘Z` | 撤销 / 重做（编辑文字时归输入框） |
| `⌫` / `⌦` | 删除选中的标注 |

⚠️ **`Esc` 与覆盖层是「同一架梯子，出口朝相反方向」—— 这是刻意的**（2026-10-03 定，设计稿同判）：

| | 底 | 退到底做什么 | 为什么 |
| --- | --- | --- | --- |
| 覆盖层 | **还没有东西** | **取消**，不留痕 | 什么都没产出 ⇒「没有」就是零损失 |
| 编辑器 | **已经有东西**（拼好的图 + 画的标注） | **完成并复制并关闭** | 已经产出 ⇒「带走」才是零损失 |

**硬统一成一个字面动作，会让一边变危险**：覆盖层的 `Esc` 变成"完成"就没有退路；
编辑器的 `Esc` 变成"取消"，就是**按一下丢掉几分钟的活**。

⇒ 统一的是**规则**（退最里面那一层；退无可退时朝"不丢东西"的方向退），**不是字面**。

**「丢弃」在编辑器里由 `✗` 单独承担** —— 必须用手点，不能让人顺着下意识按出来。
危险的动作要"够不着"，不能只是"标红"。

### B.1 工具栏（工具 ≤ 9 个，硬约束）

工具（左）：**选择 / 矩形 / 椭圆 / 箭头 / 画笔 / 文字 / 马赛克 / 模糊 / 裁剪** —— 9 个，到顶。

然后是：**文字预设**（仅当选了文字工具时出现）→ **色板 6 色** → **尺寸 3 档** →
**缩放** → **识别文字** → **撤销 / 重做** → **保存 / 取消 / 完成**。

**工具在左、动作在右，取消与完成永远压在最右。** 用 ✗ / ✓ 这类不需要解释的符号。

**文字预设**：两个预设「文字」与「序号」；选「序号」时旁边出现"从几开始"的当前值，
可以直接改（1–99）。这是一个预设，**不占独立工具位**。

> 覆盖层与编辑器**同一个功能必须用同一个图标**。用不同图标，用户会以为是两个东西。

### B.2 画布上的直接操作

- 拖拽移动标注、拖角改大小；点空白取消选择
- **双击文字** → 就地改内容
- 裁剪：拖出保留框 → 确认；取消则恢复
- `Delete` 删除选中的标注
- 滚轮 / 手势缩放与平移；首次进入自动适配窗口

### B.3 识别文字的结果面板

浮在画布上、**不挤占画布宽度**（结果只是"顺手看一眼"的东西）。

三种状态必须都有文案，**不许留白**（留白会让人以为坏了）：

| 状态 | 内容 |
| --- | --- |
| 进行中 | 「正在识别…」（识别本身是异步的，首次可能很久） |
| 有结果 | 可选中、可 ⌘C 的**只读**文本 + 「全部复制」 |
| 没有 / 失败 | 明确说明是"这块区域没有文字"还是"失败了" |

> 用只读而不是可编辑：用户要的是"能划、能 ⌘C"，不需要改 ——
> 可编辑会多出"改了但没生效"这一整类疑惑。

## C. 偏好设置（**正好 4 页**，硬约束）

### C.0 跨四页的共同逻辑

1. **没有「确定 / 应用」按钮。** 改一下**立刻生效、立刻落盘**。
   这类工具的偏好项都是一眼能看出效果的小开关，而"改完忘了点应用"是这类窗口最经典的坑。
2. **正好 4 页。** 多一页的收益远小于破坏一条写进产品文档的约束。
   所以后来加的 Pro 状态区是**接在「通用」页底部**，而不是新增第 5 页。
3. 每一页里的每一项，都要有一句话说明**它到底改变什么** ——
   这一页上的每一项都直接改变用户看到的结果，"改了但没生效"必须是不可能的。

### C.1 「通用」页

| 项 | 含义 | 默认 | 备注 |
| --- | --- | --- | --- |
| 截图后播放提示音 | 截成功时播一声系统音效 | **开** | 关掉的实际场景是"连着截很多张时不想被打断" |
| 开机时自动启动 | Marquee 常驻菜单栏，开机就有 | **关** | 见下方"失败必须回滚" |
| **Pro 状态区**（底部） | 当前权益状态 + 「升级到 Pro」+「恢复购买」 | —— | 见 C.5 |

**开机自启动有一条必须被表达的逻辑**：注册到系统登录项**可能失败**。
失败时界面必须**把开关拨回去**，并给出原因与去哪看 ——
否则界面显示"已开启"而系统里没有，用户只能靠重启去发现。

> 目标系统上，这一页**刻意没有**"截图后是否自动复制到剪贴板"这一项：
> 当前链路无条件写剪贴板，摆一个兑现不了的开关比少一个开关糟糕得多。

### C.2 「截屏」页

| 项 | 含义 | 默认 | 备注 |
| --- | --- | --- | --- |
| 截图里包含鼠标指针 | 截图是否把光标画进去 | **关** | 指针会挡在内容上；"要的是那张图、不是我的鼠标在哪" |
| 窗口截图带阴影 | 截某个窗口时带系统阴影 | **开** | 在覆盖层里按 `⌥` 可以**临时反转**这一项 |
| 延时截图 | 按快捷键后等几秒再出现覆盖层 | **不延时** | 有限档位：不延时 / 3 / 5 / 10 秒 |

**延时为什么是"覆盖层出现**之前**"那几秒** —— 覆盖层一旦出现就吃掉所有鼠标事件，
那时候再等几秒，用户反而什么都摆不了。

> 延时用**有限档位**而不是任意数字：一个数字输入框要配校验、错误提示、越界夹取，
> 而用户要的只是"给我几秒钟摆一下"。

### C.3 「输出」页

| 项 | 含义 | 默认 | 备注 |
| --- | --- | --- | --- |
| 保存位置 | 图存到哪个文件夹 | `~/Pictures/Marquee` | 旁边有一个"选择…"打开系统选文件夹面板 |
| 图片格式 | PNG（无损）/ JPEG / HEIC | PNG | 后两者有损 |
| 质量 | 有损格式的压缩质量 | —— | **只在有损格式下有效** —— 这一条的"无效"状态要能被看出来 |
| 文件名模板 | 例如 `Marquee-{date}-{n}` | 有默认值 | 见下方变量说明 |
| 可用变量提示 | `{date} {time} {n} {app} {title}` | —— | 常驻提示，因为没人记得住变量名 |

**必须说明的一条**：只有按 `⌘S` 或点「保存」时才写盘。
也就是说"保存位置"这个设置**与日常截图无关** —— 不说明的话，
用户会以为每截一张就往那儿存一份。

### C.4 「快捷键」页

只有一件事：**全屏截图的全局快捷键**。

- 一个录制控件：点一下 → 显示"按下新的组合…" → 用户按什么就录什么
- 显示**当前**生效的组合
- **冲突要明确告知**，并把显示**回滚**到原来那个（然后用户可以立刻再试）
- 一个「恢复默认」按钮
- 一句说明：全局生效（应用不在前台也能触发）

### C.5 Pro 状态区（在「通用」页底部）

**状态文字**（六种，都由权益判定整句推出，界面不许自己拼）：

| 状态 | 文字大意 |
| --- | --- |
| 还在确认 | 正在确认… |
| 免费版 | 免费版（最近截图保留 N 张） |
| 试用中 | 试用中，还剩 N 天 |
| 已购买 | 已购买，谢谢 |
| 被撤销 | 这笔购买已被撤销 |
| 找不到 | 这个账号下找不到这笔购买 |

**两个按钮**：

- **升级到 Pro** —— 已购买时变成「已购买」并置灰
- **恢复购买** —— **永远可点**。App 审核要求可恢复，而且"我明明买过"的人
  第一件事就是找这个按钮。

**恢复购买的结果必须如实回报**：恢复了 / 这个账号下没有可恢复的 / 失败了。
这是用户主动点的动作，**悄悄失败等于骗他**。

## D. 最近截图面板

**为什么是弹层而不是一个"图库窗口"**：要解决的是"**刚**截的图找不到了"。
独立图库窗口会带来窗口管理、搜索、分组、拖拽导出 —— 那是另一个产品。

### D.1 内容

- 最多列 **12 条**（再多性能与"看得过来"两方面都不划算）
- 每条一行：**缩略图** + **时间**（如 `10月3日 18:47`）+ **尺寸** `1234×768 px`
  （有标注时追加 `· 3 个标注`）+ `[编辑]` `[删除]`
- **缩略图本身就是"复制到剪贴板"按钮** —— 点图就该拿到图，这是最自然的那一下
- 空态：一句话 + 告诉用户按什么键能截第一张

### D.2 两条必须清楚的动作语义

| 动作 | 语义 |
| --- | --- |
| **编辑** | 用历史里的**原图 + 标注**重开编辑器 —— 原有的标注**仍然可编辑**，不是在成品图上再画 |
| **删除** | 从历史里删掉，**连磁盘上的文件一起清** |

### D.3 免费版的配额说明

面板底部一行小字：「免费版只保留最近 N 张 · 升级到 Pro 可保留全部」。

**这里刻意只放一行字，不弹卡片。** 截图是高频动作 ——
每截一张都弹一次"要不要升级"等于自杀。（只有三个**入口**会弹卡片，配额类不弹。）

## E. 菜单栏下拉菜单

**约束：≤ 6 项。当前 5 项 + 一条分隔线。**

```
截屏            （显示当前快捷键）
滚动截屏        （免费版带小锁，但**可点**）
最近截图
设置…            （⌘,）
──────────
退出 Marquee     （⌘Q）
```

**逻辑要点**：

1. **「滚动截屏」在免费版带一把小锁，但绝不置灰。** 置灰了用户点不动，
   就永远看不到那张解释为什么的卡片。**只换图标，不动可用性。**
   锁的状态在**每次展开菜单时现算**（而不是等谁推一个通知过来 ——
   那要求"权益变了"必须通知到每一个界面，漏一处就是"买完了锁还在"）。
2. **「最近截图」不是子菜单。** 子菜单放不下缩略图，而"看不见缩略图"
   就等于回到"我记不清哪张是哪张"。
3. **菜单项旁边的快捷键是"告知"，不是"触发"。** 全局触发由系统级热键负责，
   菜单里显示它纯粹是告诉用户现在是哪个键。
4. 未实现的项**直接不出现**，不要放一个点了没反应的假入口。

## F. 钉图（钉在屏幕上）

**用途**：把一张图钉在屏幕上当参照物，对着改别的东西。

### F.1 本体

- 无边框、**不抢键盘焦点**（它一旦成为 key window，用户切回来时焦点会被吸走 —— 而那正是它想避免的）
- **跟着切换 Space**（当参照物时你要它在眼前，而不是留在原来那个桌面）
- 可拖动
- **滚轮缩放**，锚点在左上角
- 一圈细描边 —— 白底截图放在白底窗口上时，没有它就是"什么都没出现"

### F.2 控制条（3 个按钮 + 整条可当拖动把手）

**钉图上没有任何文字标签，所以这三个按钮是"它们干什么"的唯一出口。**

| 按钮 | 作用 | 必须表达的 |
| --- | --- | --- |
| 鼠标穿透 | 开关；开着时点击会落到下面的应用 | **开着的时候要高亮** —— 它是"异常状态"，不高亮用户会以为鼠标坏了（点了什么都没反应） |
| 不透明度 | 点一下换下一档 | **它同时是按钮和读数** —— 图标本身要能看出当前是多少 |
| 关闭 | 关掉这张钉图 | 不可逆 |

**控制条必须始终可交互，即使本体正在穿透** —— 这是"穿透怎么关掉"的唯一出口。

**整条空白处 = 拖动把手**（钉图上没有别的可抓的地方）。

### F.3 两条逻辑

- **多张共存**：可以同时钉好几张。
- **工具提示是唯一的说明**：钉图上没有文字标签，而"按了才知道"
  对不可逆操作（关闭 / 穿透）来说太晚了。悬停必须给出人话解释。

## G. 延时倒计时

按了快捷键、设了延时之后的等待界面。

- 出现在屏幕**中央**，显示一个**大数字**逐秒递减
- **可点穿**：等待期间用户还能操作下面的东西（这正是"能中止"的补偿）
- **不抢焦点、不能中止**：一个不能成为 key window 的窗口收不到键盘，
  要支持 `Esc` 就得再挂一层全局监听 —— 而这段等待最长 10 秒，收益远小于代价
- 延时为 0 时**什么都不显示**，直接进入覆盖层（"延时 0"与"不延时"行为完全等价）

## H. 权限与错误提示

这三个是**系统模态对话框**，不是我们自绘的界面。但它们的**文案与按钮**要设计：

| 场景 | 标题 | 说明 | 按钮 |
| --- | --- | --- | --- |
| 缺屏幕录制权限 | 需要「屏幕录制」权限 | 到哪勾选；**列表里找不到 Marquee 怎么办**（拖进列表） | 打开系统设置 / 在 Finder 中显示 / 稍后 |
| 已勾选但未生效 | 同上 | "macOS 要求应用重启后才生效，请退出再打开" | 同上 |
| 截图没完成 | 截图没有完成 | 原因 | 好 |
| 快捷键没生效 | 快捷键没有生效 | 原因 | 好 |

> 「列表里找不到 Marquee」那条不是冗余：这是这类权限最常见的卡点，
> 而用户卡在那里时完全不知道下一步做什么。

## 四、给设计方的请求

1. **先给结构，再给像素。** 最需要的是"为什么这一页的主次是这样"，
   而不是一张更好看的图。
2. **反对就说。** 上面每一条"硬约束"都是产品决策，不是实现细节。
   如果你认为某条必须打破才能做好，请单独说明理由 —— **不要默默绕开**。
3. **不要设计需要新弹窗、新页面、新步骤的方案。** 这个产品的全部价值就在"少一步"。
4. **深色优先。** 主界面（覆盖层、钉图、编辑器）始终压在任意屏幕内容上，
   必须是深色、始终可读 —— 包括压在一张纯白网页上的时候。
5. **每一条"状态"都要有对应的样子。** 这份文档里凡写了"进行中 / 失败 / 空 /
   没授权 / 被锁 / 不可用"的地方，都请给出它长什么样 ——
   **留白会让人以为坏了**，这是这个产品里最贵的一类错。
