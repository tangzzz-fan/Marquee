## 0. 它什么时候出现 / 与前几轮的根本差别

**只有长截图结束后会进它。** 普通截图**不经过它** —— 那一路是"就地标注 → 直接进剪贴板"。

⇒ 三条后果：

1. **它是独立窗口**（会与其它应用并排），但**固定深色**、不跟系统外观 ——
   它是「**看图的台面**」：图本身可能是任意颜色，深色台面让图突出。
   （覆盖层也深，但理由不同：覆盖层深是因为它压在屏幕内容上。）
2. **停留时间最长**：用户会在里面待几十秒到几分钟，反复改。所以它比覆盖层更接近
   一个"工具窗口"，空间与层级要撑得住。
3. **进去的时候用户已经"有东西"了** —— 一张拼好的长图。编辑器不许让他觉得自己
   从头来过。

## 1. 工具栏（**工具 ≤ 9 个，硬约束**）

**工具（左）**：选择 / 矩形 / 椭圆 / 箭头 / 画笔 / 文字 / 马赛克 / 模糊 / **裁切** —— 9 个，到顶。

**然后是**：文字预设 → 色板 6 色 → 尺寸 3 档 → 缩放 → 识别文字 → 撤销 / 重做 →
**保存 / 取消 / 完成**。

**三条必须成立**：

1. **工具在左、动作在右，取消与完成永远压在最右**，用 ✗ / ✓ 这种不需要解释的符号。
2. **同一个功能在两处用同一个图标。** 覆盖层有「文字」工具，编辑器也有 ——
   图标不同，用户会以为是两个东西。
3. **「序号」是文字工具的一个预设，不占独立工具位**（否则撑破 9 个的上限）。

**文字预设**：两个预设「**文字**」与「**序号**」；选「序号」时旁边出现"从几开始"的当前值，
可以直接改（1–99，之后每放一个自增）。它是**预设**，不是工具。

**尺寸 3 档与覆盖层同源**：含义随当前工具变（线宽 / 打码强度 / 字号），形状也跟着变。
⚠️ 但**编辑器里这几个值的单位是「原图像素」，覆盖层里是「点」** —— 两者不是同一组数字，
这是刻意分开的（同一个数字在 2x 屏上差一倍）。**请保持这个区分可见**。

## 2. 画布上的直接操作

- 拖拽移动标注、拖角改大小；点空白取消选择
- **双击文字** → 就地改内容
- **裁剪**：拖出保留框 → 确认；取消则恢复
- `Delete` 删除选中的标注
- 滚轮 / 手势缩放与平移；**首次进入自动适配窗口**

**标注是可以反复改的对象**，不是在成品图上再画 —— 这是这个产品相对竞品的核心手感优势。

---

## 3. 识别文字的结果面板

浮在画布上、**不挤占画布宽度**（识别结果只是"顺手看一眼"的东西）。

**三种状态必须都有文案，不许留白** —— 留白会让人以为坏了：

| 状态 | 内容 |
| --- | --- |
| 进行中 | 「正在识别…」（识别是异步的，**首次可能很久**） |
| 有结果 | 可选中、可 `⌘C` 的**只读**文本 + 「全部复制」 |
| 没有 / 失败 | **明确区分**"这块区域没有文字"与"识别失败了" |

> 用只读而不是可编辑：用户要的是"能划、能 ⌘C"，不需要改 ——
> 可编辑会多出"改了但没生效"这一整类疑惑。

## 4. 键盘

| 键 | 作用 |
| --- | --- |
| `⌘Z` / `⇧⌘Z` | 撤销 / 重做（编辑文字时归输入框） |
| `⌘S` | 保存到磁盘并关闭 |
| `Esc` | **退一层**（丢输入 → 取消裁剪 → 退回「选择」工具 → 取消选中 → 关闭窗口） |
| `⏎` | **确认**（＝工具栏那颗 `✓`：复制并关闭）。裁剪进行中＝应用裁剪 |
| `Delete` | 删除选中的标注 |

✅ **`Esc` 与 `⏎` 在这两个界面上已经统一（2026-10-03 定）**：

```
Esc = 退一层，到底 = 取消        ⏎ = 确认 / 提交
```

- **覆盖层**：`Esc` 四级退（收弹层/卡片 → 丢输入 → 取消工具 → 取消选区 → 取消整次截图）
- **编辑器**：`Esc` 逐层退（丢输入 → 取消裁剪 → 退回「选择」工具 → 取消选中 → **关闭窗口＝取消**），
  与 `✗` 是同一个动作

⚠️ **`Esc` 绝不产出。** 编辑器以前把它接成了「完成并复制」—— 于是"退出键"干了"确认"的活，
而写剪贴板是不可逆的。**要保住成果请按 `⏎` 或 `✓`。**

另：按 `Esc` 取消**不会毁掉截图本身**（进编辑器时那张图已经在剪贴板里了），
用户失去的只有这次画的标注 —— 请把 **「取消编辑」与「丢掉截图」是两回事** 在设计里说清楚。

## 5. 硬约束

- **工具 ≤ 9 个**
- **不许设计需要新窗口 / 新弹窗 / 新步骤的方案**
- 固定深色（不跟系统外观）—— 它是"看图的台面"
- 尺寸档与之相关的值，**编辑器用原图像素、覆盖层用点**，这个区分要看得见
