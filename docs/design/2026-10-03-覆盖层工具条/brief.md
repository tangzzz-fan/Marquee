## 一、这是什么

**Marquee** 是一个 macOS 截图 + 标注工具（原生 AppKit，不是网页、不是手机 App）。

一句话的体验目标：

> 按一下快捷键 → 屏幕冻住 → 框出要截的那块 → **就地图标注** → 直接进剪贴板。

用户是每天截十几张图的人（写文档、报 bug、做教程）。他们对"多一步弹窗"极度敏感 ——
**中途不出现任何"要不要保存 / 保存到哪"的提问**，是产品的全部价值。

## 二、这一轮只做一件事

**覆盖层底部那条浮动工具条**，以及它周边的三处配套显示。

不要做编辑器、不要做偏好设置、不要做引导页 —— 那些下一轮。

## 三、它出现在什么时候

按下全局快捷键后，**整块屏幕**变成覆盖层：

- 屏幕整体压暗（暗化蒙层）
- 用户拖出一个矩形选区，**选区外面保持压暗、选区里面是原始亮度**
- 松手后选区定住，**工具条出现在选区下方约 10 点处**，左对齐
- 选区贴着屏幕底部放不下时，工具条**翻到选区上方**（要给出这一态的设计）
- 覆盖层的背景**是用户真实屏幕上任意内容**（可能是白底文档，也可能是深色 IDE），
  所以对比度只能在**深色材质**上验过才算数

## 四、现在的工具条（要改的就是它）

实测尺寸（要按点还原）：

```
整条：545 点宽 × 40 点高
圆角：10        内边距：6（左右）
每格：28 × 28    格间距：4      组间距：9
组间分隔线：1 点宽
```

**15 格，分四段**（图标全是 macOS SF Symbols 的白色模板图标）：

```
[矩形][椭圆][表情][箭头][画笔][马赛克][文字]  │  [样式]  │  [识别文字]  │  [撤销][重做][保存][钉图][✗][✓]
└──────── 7 个绘制工具 ────────┘   └ 1 ┘    └  1  ┘   └──────── 6 个动作 ────────┘
```

- **✗ 是珊瑚红、✓ 是绿**（这两处是整条仅有的颜色语义，已验证对比度 ≥ 4.5:1）
- 其余图标全是白的 —— **落在深色玻璃材质上，整条的层次感可能太平**（这是我的怀疑之一）
- 点「样式」会在工具条**外侧**弹出一个面板：**色板 ×6 + 尺寸 ×3**
- 「尺寸」那三档按当前工具换含义：画图形是**线宽**（圆点 2/4/8）、
  画打码是**打码强度**（方块 4/8/16）、写文字是**字号**（字母 A 18/28/44）
- 「识别文字」「钉图」是**动作不是工具**（点一下就执行，不改变"当前在画什么"）
- 「最近截图」等 Pro 能力被挡住时，**对应那一格图标右下角补一个小锁**（常显）

**已知的、刻意为之的取舍（不要"修"它们，它们是有意为之）**：

- 「选择」**不占格** —— 没选工具时按住标注就是选中它、可以拖动
- 「模糊」**不占格**（只剩「马赛克」）—— 渲染能力还在，只是不给入口

## 五、必须遵守的硬约束

| # | 约束 | 为什么 |
| - | --- | --- |
| 1 | **整条必须放得进 1024 点的屏**（现在 545 点，不能变宽） | 这是产品文档定的硬线 |
| 2 | 模式弹窗 **0 个** | 不做"选择模式"这类中间步骤 |
| 3 | 深色优先 | 它盖在用户真实屏幕上，只验浅色不算数 |

> ⚠️ 约束 1 是**已经写进产品文档**的。如果你认为必须打破它才能做出好体验，
> **请单独提出来说明理由**，我会评估；但不要默认它可以动。

## 六、我怀疑的问题（是线索，不是结论；请你判断）

1. **15 格是密度上限**。「样式」一个入口里塞了**两样东西**（色板 + 尺寸），
   而用户从图标上看不出里面有两样。
2. **颜色语义只有两处**（✗ 红 / ✓ 绿），其余全白 —— 整条的层次可能太平。
3. **三个"组"的边界靠 1 点分隔线**，在 40 点高的条上够不够清楚，我没有把握。
4. **「识别文字」和「钉图」混在动作区里**，但它们与「撤销/重做/保存」的性质并不同
   （前者是"对选区做的事"，后者是"对本次会话做的事"）。

## 七、请交付什么

1. **整条工具条的重设计**（在原宽度预算内；靠更好的分组 / 更少格数换来清楚层次是加分）
2. **各状态的差异**：默认 / 悬停 / 选中 / 被锁（Pro）/ 禁用（如"撤销"没东西可撤时）
3. **两个附带态**：
   - 工具条翻到选区**上方**时的样子
   - 长截图进行中：条上方多一行**进度提示**（已拼多少像素 / 多少帧 / 是否已到底）——
     现在是一行等宽字体数字，位置与样式都像补丁，我怀疑它是全条最不协调的地方
4. **尺寸标注**（我要按点还原到 SwiftUI / AppKit）
5. **先给结构、再给像素**：我最需要的是"为什么这 15 格该是这 15 格、为什么这样分组"

## 八、不用做的事

- 不需要中文文案（图标为主，少量提示文字我会自己写）
- 不需要做成网页/移动端 —— 这是 macOS 桌面端，**对齐 macOS 原生观感**（SF Symbols、系统材质）
- 不要设计需要新弹窗的方案
