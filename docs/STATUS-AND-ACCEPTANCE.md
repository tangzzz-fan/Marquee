### B. 已知的未验证高风险项（不影响开工，但影响"能不能交付"）

| # | 项 | 为什么是风险 |
| --- | --- | --- |
| B1 | **应用未激活时覆盖层的键盘是否生效** | 面板用 `.nonactivatingPanel`（不抢焦点是刻意的），但 `Esc`/`⏎`/方向键能否收到没验过。**这是覆盖层最没把握的一条** |
| B2 | **滚动截屏抓帧期间面板失焦后 `⏎`/`Esc` 失效** | 抓帧要鼠标穿透，用户去点了别的应用就可能丢 key 焦点。无解则需全局键盘监听 —— 但那要输入监控权限，与"不申请多余权限"冲突 |
| B3 | **真实滚动场景** | sticky header / 惯性未停即抓帧 / 页面内有视频动图。合成数据覆盖不到，SPIKE 标为 M13–M15 |
| B4 | **超长图在编辑器里的渲染** | SPIKE E5 标为风险项：Canvas 可能按需光栅化整幅。1200×9000 级别需实测 |
| B5 | **耗时预算无实测记录** | "按下快捷键 → 剪贴板可用 ≤ 150 ms"目前只有日志埋点，没有真实数字 |
| B6 | **混合 DPI / 多显示器** | 需要外接一块非 Retina 屏才能验（SPIKE M5） |

### C. 环境限制（不影响你，只影响我这边）

我这侧的 shell 被沙箱包裹，`swift-plugin-server` 启动时自己再套一层沙箱会被 SIGKILL，
于是 `xcodebuild` 报 SwiftUI 宏 `produced malformed response`。
**判别方法**：`./scripts/test.sh`（走 SwiftPM）能过、`./scripts/build.sh` 不能 → 一定是宿主沙箱在挡，别动代码。
我这边的替代验证：App 层用 `swiftc -typecheck -I Modules/.build/out/Products/Debug App/Sources/*.swift`（已过）。
详见 `docs/DEV-NOTES.md` 第 4.1 节。

## 3. 人工验收方案

### 0. 一次性准备

```bash
cd /Users/tango/Developments/Marquee
./scripts/build.sh          # 产物固定在 <repo>/DerivedData/Build/Products/Debug/Marquee.app
```

| 检查 | 命令 / 动作 | 期望 |
| --- | --- | --- |
| 签名稳定 | `codesign -dvvv DerivedData/Build/Products/Debug/Marquee.app \| grep -E "Authority\|flags="` | `Authority=Apple Development…`、`flags=0x0`（**不是** `adhoc`） |
| 清掉历史授权条目 | `tccutil reset ScreenCapture dev.tango.Marquee` | 会清掉所有 Marquee 授权记录，之后需重新勾选一次（只做一次） |
| 状态一页纸 | `DerivedData/Build/Products/Debug/Marquee.app/Contents/MacOS/Marquee -marqueeDiagnostics` | 权限状态 / preflight 原始值 / 当前快捷键 / 注册结果 / 构建签名身份 |

> `-marqueeRequestPermission` 可单独触发"登记进「屏幕录制」列表 + 请求授权"，不必等按快捷键。

### A. 权限生命周期（ticket 02、06）

| # | 前置 | 步骤 | 预期 |
| --- | --- | --- | --- |
| A1 | 撤销屏幕录制授权（`tccutil reset ScreenCapture dev.tango.Marquee`） | 启动 Marquee，按 `⌃Q` | 看到明确说明 + 「打开系统设置」按钮；**不弹主窗口、不静默失败** |
| A2 | 同上 | 点「打开系统设置」 | 直达「隐私与安全性 → 屏幕录制」面板 |
| A3 | 同上 | 在系统设置里找 Marquee | **列表里应有 Marquee**（若没有，点「+」手动添加，路径见 §0） |
| A4 | 已勾选 Marquee | 不重启，直接再按 `⌃Q` | 按设计会提示"请退出并重新打开"；**记录 macOS 27 的真实行为**（是否真的必须重启） |
| A5 | 重启 Marquee 后 | 按 `⌃Q` | 正常进入覆盖层，不再要权限 |

| A7 | — | 重新构建一次后再按 `⌃Q` | **不应**再要求授权（这是稳定签名修复的验收点） |

### B. 覆盖层行为（ticket 03；SPIKE B1–B4）

**B 组是覆盖层最难的部分，也是自动化完全覆盖不到的部分。**

| # | 前置 | 步骤 | 预期 |
| --- | --- | --- | --- |
| B1 | 任意应用在前台 | 按 `⌃Q` | 蒙层盖住菜单栏与 Dock；**应用保持在前台**（不被拽走） |
| B2 | 主窗口在 Space 1，切到 Space 2 | 在 Space 2 按 `⌃Q` | 蒙层出现在 **Space 2**，系统不切 Space |
| B3 | 目标应用原生全屏 | 触发 `⌃Q` | 蒙层可见可交互 |
| B4 | 开启 Stage Manager | 悬停各窗口 | 高亮框贴合，无偏移 |
| B5 | 外接一块非 Retina 屏 | 跨屏拖选区 | 蒙层两块屏都有；选区尺寸/坐标/输出像素正确，无错乱 |
| B6 | — | 触发后不碰鼠标，直接按 `Esc` / `⏎` / 方向键 | **覆盖层不激活本应用时这些键是否生效**（B1 风险项）；`Esc` 一次收掉**所有**屏的蒙层 |
| B7 | 磁盘上找个长页面 | 拖选区 → `⏎` → 检查输出 | 输出图里**没有蒙层**、没有 Marquee 自己的窗口 |
| B8 | 触发覆盖层，悬停某个窗口使其高亮 | 按 **`⌘Tab`** 切到别的应用，松手后**不动鼠标**再看 | 高亮应当跟着切到新前台应用的窗口上（清单与悬停都要刷新）；且**看得到系统的应用切换器**（不被蒙层整个盖住）—— 后者是待实测项 |

| --- | --- | --- |
| F1 | 选区 / 窗口 / 整屏确认后 | 进入编辑器，画布是刚截的图；滚轮平移，`⌘`+滚轮或工具栏加减缩放 |
| F2 | 画矩形与椭圆 | 松开后仍可被选中，四角有控制点 |
| F3 | 拖动改位置、拖角改大小、点色块改色、点线宽改粗细 | 每步都生效 |
| F4 | `⇧` 点第二个对象，一起移动 / 改样式；`Delete` | 多选与删除正确 |
| F5 | `⌘Z` / `⇧⌘Z` | 逐级撤销 / 重做 |
| F6 | `Esc` | 复制成品到剪贴板并关闭；粘贴出来的图**有标注**，像素尺寸与截图一致 |
| F7 | **专门验一次方向** | 粘贴出来的图**不是上下颠倒的**（这是本次修掉的缺陷，纯色图看不出来，请用有上下差异的内容） |
| F8 | 选「箭头」，从 A 拖到 B | 箭头从 A **指向 B**；头部大小跟着线宽变；拖太短（几像素）不留下东西 |
| F9 | 选「画笔」，按住画一条曲线 | 跟手无延迟；松手后是一整条**圆头**折线（不是几段带尖刺的直线） |
| F10 | 选「文字」，在图上点一下 | 出现输入框，回车确认；文字落在点下的位置，且**不是镜像的** |
| F11 | 双击已有文字 | 再次出现输入框，可改内容；改完框的宽度跟着变、左上角不动 |
| F12 | 选「文字」工具 → 切到「序号」，连点三下 | 依次出现 `1.` `2.` `3.`；改「起始」为 7 后下一个是 `7.`；删掉 `2.` 后剩下的是 `1.` `3.`（**不重排**） |
| F13 | 移动一个箭头 / 画笔 | 图形**和**框一起走（不会"框走了线留在原地"）；四角控制点可把它拉长压扁 |
| F14 | 选中文字后点工具栏那一排数字 | 此时改的是**字号**（不是线宽）；拖文字的控制点也是缩放字号 |
| F15 | 选「马赛克」，在有文字的部位涂一块 | 涂的地方变成**块状**（不是糊的）；点工具栏那一排数字可调**块大小** |
| F16 | 选「模糊」涂一块，对比两者 | 模糊是**糊**、马赛克是**方块** —— 两种效果必须明显不同 |
| F17 | 移动/缩放一块打码，然后 `Esc` 导出 | 导出的图里打码位置与预览**完全一致**（不是只有预览生效） |
| F18 | 点「裁切」→ 拖角调整框 → 回车 | 画布尺寸随之改变（工具栏右侧的缩放百分比会重算） |
| F19 | 裁切后 `⌘Z` | 回到完整原图，且**裁切前画的标注位置正确恢复** |
| F20 | 裁切模式里按 `Esc` | 退出裁切模式而**不是**复制并关闭（两者的 Esc 语义不同） |

## 5. 排障入口速查

```bash
# 一页纸状态（权限 / 快捷键 / 签名身份）—— "为什么权限留不住"的第一手证据
DerivedData/Build/Products/Debug/Marquee.app/Contents/MacOS/Marquee -marqueeDiagnostics

# 单独触发"登记进屏幕录制列表 + 请求授权"
... -marqueeRequestPermission

# 覆盖层 / 编辑器的开发冒烟（1.5 秒自动退出，验证创建→绘制→拆解不崩）
... -marqueeSmokeOverlay
... -marqueeSmokeEditor

# 编辑器演示：合成图 + 五类标注各一个，**不自动退出**，也不需要屏幕录制权限
... -marqueeDemoEditor

# 截图耗时与落盘结果
log show --last 5m --predicate 'subsystem == "dev.tango.Marquee"' --style compact

# 清掉所有 Marquee 的屏幕录制授权记录（之后需重新勾选）
tccutil reset ScreenCapture dev.tango.Marquee

# 放大镜尺寸（下一次唤起覆盖层即生效，不必重启）
defaults write dev.tango.Marquee lens.samplePoints -float 32   # 取样区边长（点），8...200
defaults write dev.tango.Marquee lens.zoom -float 4            # 倍数，1...12
defaults write dev.tango.Marquee lens.gap -float 22            # 与光标的间距，0...80
defaults delete dev.tango.Marquee lens.zoom                    # 单项回默认
```

> `-marqueeDiagnostics` 最后一行是**实际生效的构建签名身份**。权限问题先看它：
> 身份不稳定（ad-hoc）＝ macOS 每次构建都当成新应用。
