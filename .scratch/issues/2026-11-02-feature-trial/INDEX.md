# Marquee · 功能体验（每项 3 天）· Ticket 索引

**日期**: 2026-11-02
**分支**: `feat/monetization-shape`（从 `main` 切出）
**方法论**: Matt Pocock `to-tickets`（tracer-bullet 垂直切片 + 阻塞边）
**输入**: 本轮对话确认的方案 —— 商店页第一印象 + 每项 Pro 能力 3 天体验

---

## 1. 要解决的问题

app 已上架，免费版本身给得相当完整（截图三件套 / 窗口识别 / 全部标注 / 取色 / 剪贴板 / 偏好设置全开）。
但有两处让用户走不到「想要更多 → 买断」这条路上：

1. **下载前**：商品页上「免费」两个字排得太靠后，第一眼是 `Marquee Pro ¥36.00`；
2. **下载后**：免费用户点任意 Pro 入口，直接被弹一张要钱的卡片 —— 中间没有「试一下」这一环。

## 2. 切片原则

与 `2026-09-30-marquee-mvp` 一致：每条票是一条**窄而完整**的路径，落地即可独立演示。
票号按依赖顺序，阻塞边只写真正卡住它的那些。

## 3. 全量总览

| # | Ticket | 阻塞于 | 交付的可演示行为 |
| --- | --- | --- | --- |
| 01 | 体验账本与判据 | 无 | 给定「某项首次使用于某时刻」，能判出未开始 / 还剩几天 / 已结束；3 天整才结束 |
| 02 | 钉图的 3 天体验（端到端） | 01 | 免费用户点钉图**直接用上**；第 4 天再点才弹卡片 |
| 03 | 识别文字与滚动截屏接上同一套体验 | 02 | 两个入口各自独立 3 天，行为与钉图一致 |
| 04 | 商店页文案改造 | 无 | 商品页第一眼能看出「免费下载、解锁可选」；宣传文本当天可改 |

## 4. 明确不做

- **不拆商品**：仍是一个 `com.tango.marquee.pro` ¥36 非消耗型，`Entitlement` 枚举不动
- **不动免费边界**：免费 6 类能力一条不改
- **不动老用户权益**：买断交易永久有效
- **不碰现有 7 天整包试用**：它作为「想整体试」的第二条路保留
- **不改「最近截图」额度**：体验只覆盖三个入口，不限历史仍是免费 5 张

## 5. 与既有的关系

- `Entitlement` 从「全局判定」扩成「全局 + 分项体验」，但**判据仍然只有一处**（`ProCard.content`）
- 账本存 UserDefaults，与 `EntitlementCache` 同一套「存事实不存结论」的做法
- 3 天复用 `TrialPolicy.secondsPerDay`，不另写 86400
