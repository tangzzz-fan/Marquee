# 02: 钉图的 3 天体验（端到端）

**What to build:** 免费用户在覆盖层里点「钉图」，图**当场钉出去**，没有任何卡片、没有价格。这是他的第一次，账本从这一刻开始计时。三天之内再点，照样直接用。

第 4 天再点，原地弹卡片：说清「钉图的 3 天体验已结束」，主按钮给「7 天试用全部功能」（如果整包试用还没用过），否则给「了解 Pro」，次按钮「恢复购买」。关掉卡片，选区与标注一个字都不动，他仍能用免费能力把这次截图做完。

工具条上那一格在体验有效期内**不显示锁**，到期后才有锁 —— 锁与「点了会不会弹卡片」必须同源。

「记录首次使用」只允许有一个写点。三个入口谁都不许自己写账本，否则「某一处忘了记」会表现为那一项永远可以免费用。

**Status:** ready-for-agent

- [ ] 体验有效期内工具条该格无锁；到期后出现锁

- [ ] 权益还没查完（unknown）时点钉图 → 放行，不弹卡片
