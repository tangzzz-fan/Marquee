# 01: 体验账本与判据

**What to build:** 免费用户对某一项 Pro 能力有各自独立的 3 天体验窗口，从该项第一次被使用的那一刻开始计时。给定「某项首次使用于某时刻」，能判定它现在处于「未开始 / 进行中（还剩几天）/ 已结束」；3 天整才算结束，剩 0.2 天仍报 1 天。系统时间被往回拨时天数夹到 3，不出现「还有 9 天」。

「最近截图不限量」不参与体验 —— 它不是入口，是数量上限，用户截第 6 张时无法感知「体验开始了」。它仍按免费 5 张处理。

账本要能落到本地并在下次启动读回来；读到写坏的数据时当作空账本，不崩溃、不把 `nil` 兜成某个合法时刻。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 未开始 → 放行；开始后 1 天 → 放行且剩 2 天
- [ ] 剩 0.2 天报 1 天；满 3 天整才结束
- [ ] 系统时间往回拨时天数夹到 3
- [ ] 体验时长参数写 0 时夹到 1，不允许「一用就结束」
- [ ] 每项独立：开始了钉图不影响识别文字的窗口
- [ ] 「不限历史」不受体验影响，永远是免费 5 张
- [ ] 账本读写往返；损坏数据 → 空账本；未知项名被忽略
- [ ] 全程不读系统时钟，`now` 由外部传入
