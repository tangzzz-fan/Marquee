# 14: 钉图（Pin）

**What to build:** 把一张截图钉在屏幕最上层，做设计对照、临摹参考时不会因为切窗口而丢失。钉住的图可以缩放、调半透明、鼠标穿透（不挡下面操作）、随时关闭。

**Blocked by:** 07

**Status:** ready-for-agent

## 设计约束（已定）

- 钉图窗口复用编辑器的渲染路径，不另造一套绘制
- 鼠标穿透是必须项（否则钉图会挡住下面的操作，反而更麻烦）
- 钉图不进入 Dock、不抢焦点

## Acceptance criteria

- [ ] 编辑器或截图结果可一键"钉到屏幕"，图出现在屏幕最上层
- [ ] 钉住的图不抢焦点，操作其他应用时它不消失也不闪烁
- [ ] 可缩放（含滚轮缩放），可调半透明
- [ ] 可切换鼠标穿透；穿透开启时鼠标点击能正常落到下方应用
- [ ] 可关闭；关闭后不留残影、不残留窗口
- [ ] 多张钉图可共存且互不干扰
- [ ] 钉图在切换 Space 后的行为明确且合理（跟随或保持在原 Space，需记录实测结论）
