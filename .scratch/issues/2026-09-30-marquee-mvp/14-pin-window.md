# 14: 钉图（Pin）

**What to build:** 把一张截图钉在屏幕最上层，做设计对照、临摹参考时不会因为切窗口而丢失。钉住的图可以缩放、调半透明、鼠标穿透（不挡下面操作）、随时关闭。

**Blocked by:** 07

**Status:** 🟡 已实现，待人工验收（2026-10-01）

## 实现记录

### 入口：覆盖层工具栏上的「钉图」

工具条 23 → **24 格 / 799 × 40 点**（仍在"放得进 1024 点的屏"的硬约束内）：

```
[选择][矩形][椭圆][箭头][画笔][文字][马赛克][模糊] │ [六色] │ [尺寸三档] │ [识别文字][钉图] │ [撤销][重做] │ [保存][✗][✓]
```

钉图是**动作**不是工具（与 OCR 同类，不占工具位）。它 = 「完成」+ 多留一份在屏幕上：
**图照样进剪贴板** —— 每条提交路径都写剪贴板是这套设计的不变量，钉图不该是例外
（否则用户按了钉图发现剪贴板没变，会以为截图没成）。

**钉在原位**：`Outcome.completed` 多带一个 `anchor`（原始选区，Cocoa 全局点），
钉图据此落在用户刚才框的那一处。整屏截图没有锚点，退化成屏幕左上角偏移 80 点。

### 为什么是**两个窗口**

鼠标穿透只能整窗生效（`ignoresMouseEvents`），而穿透打开后那个窗口收不到任何鼠标事件 ——
**点不到自己身上那个开关**。所以控制条必须是独立窗口，它永远可交互（PITFALLS 83）。

| 窗口 | 层次 | 职责 |
| --- | --- | --- |
| 钉图本体 | `.floating` | 画图；拖它移动；滚轮缩放 |
| 控制条 | `.floating + 1` | 穿透 / 不透明度 / 关闭；**整条还是拖动把手** |

控制条比本体高一层：两者都在 `.floating` 时先后顺序靠 `orderFront` 维持，
而钉图一被挪动就会重新排序、把控制条压到下面去。

### 状态与几何在 Core（`PinState` / `PinGeometry`）

缩放锚点、边界夹取、透明度档位全是纯逻辑，脱机可断言。几条刻意的决定：

- **缩放锚点是左上角**：放大时图往右下长，用户盯着的那一角不动。用中心当锚点的话，
  连滚几次图就找不着北了（Cocoa 的 `frame` 原点在左下，改高度要同步挪 y）。
- **缩放倍率相对 1:1 的显示尺寸**，不是相对当前尺寸累乘 —— 这样"回到 ×1"是个确定档位。
- **1:1 = 像素 ÷ 屏倍率**：不除的话 2x 屏上钉出来只有一半大（有测试钉住）。
- **夹取只保证"至少留一角（40 点）在屏内"**，不要求整框在屏内 ——
  钉图放大到比屏幕还大是**正常用法**（放大看局部），硬缩回去等于废掉这个功能。
- **不透明度用"循环"而不是滑块**：滑块要再加一套拖拽几何，而四档已经一眼看得出区别。
- **控制条贴右上角内侧**：贴外侧会被屏幕边缘吃掉（钉图常常贴着屏幕边），
  而"控制条不见了"与"这个功能没做"完全一样。图太小/太扁时改贴框外。

### 其余

- **不抢焦点**：面板 `canBecomeKey = false`（钉图是参照物，不该吸走焦点）
- **不进 Dock**：应用本身是 `.accessory`，天然满足
- **多张共存**：`PinPresenter` 持有数组，每张一对独立窗口
- **切 Space**：`collectionBehavior` 含 `.canJoinAllSpaces` ⇒ **跟着切**（要它在眼前）。
  ⚠️ 这一条**尚未人工实测**，见下方验收项 P9。

### 未做

- **`⌘P` 之类的快捷键**：入口只有工具栏那一格
- **缩放到"适应屏幕"** ：只支持滚轮逐格缩放
- **拖动时吸附到别的钉图/屏幕边**：暂不需要

## 设计约束（已定）

- 钉图窗口复用编辑器的渲染路径，不另造一套绘制
- 鼠标穿透是必须项（否则钉图会挡住下面的操作，反而更麻烦）
- 钉图不进入 Dock、不抢焦点

## Acceptance criteria

- [x] 截图结果可一键"钉到屏幕"（工具栏上的「钉图」），图出现在屏幕最上层
- [ ] 钉住的图不抢焦点，操作其他应用时它不消失也不闪烁
- [x] 可缩放（滚轮，锚点为左上角），可调半透明（四档循环）—— 逻辑已测，手感待人工
- [x] 可切换鼠标穿透（控制条上的按钮；穿透时控制条仍可点，PITFALLS 83）
- [ ] 穿透开启时鼠标点击能正常落到下方应用
- [ ] 可关闭；关闭后不留残影、不残留窗口
- [ ] 多张钉图可共存且互不干扰
- [ ] 钉图在切换 Space 后的行为（**已选 `.canJoinAllSpaces` = 跟随**，待实测确认）
