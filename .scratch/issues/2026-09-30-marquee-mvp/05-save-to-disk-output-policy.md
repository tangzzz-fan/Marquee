# 05: 保存到磁盘与输出策略

**What to build:** 截图后除了进剪贴板，还能按 `⌘S` 落到磁盘。文件保存在用户配置的位置，按可配置的命名模板命名，格式与质量可选。默认行为是"剪贴板优先"：不保存也能直接用；需要归档时一键落盘。

**Blocked by:** 03

**Status:** ready-for-agent

## 设计约束（已定）

- 默认保存位置：桌面；可在偏好设置中修改
- 支持格式：PNG（默认）/ JPEG / HEIC；JPEG/HEIC 的质量可调
- 命名模板支持：日期、时间、序号、来源应用名、窗口标题
- 编码走 ImageIO（`CGImageDestination`），不要自造 PNG 编码
- 落盘目录不存在时自动创建；写入失败要给明确错误而不是静默吞掉

## Acceptance criteria

- [ ] 选区截取后按 `⌘S`，文件出现在配置的目录中，格式与配置一致
- [ ] 文件名符合模板，连续截多张时序号递增且不覆盖已有文件
- [ ] 切换格式为 JPEG 并调低质量后，导出文件体积明显下降且可正常打开
- [ ] 图片写入后像素尺寸与截取时一致（Retina 下不退化为 1x）
- [ ] 保存目录被删除或不可写时，给出可理解的错误提示，且**剪贴板中的图仍然可用**（不因保存失败而丢失结果）
- [ ] 命名模板渲染有单元测试，覆盖：日期/时间替换、序号补零、非法字符过滤、超长窗口标题截断
