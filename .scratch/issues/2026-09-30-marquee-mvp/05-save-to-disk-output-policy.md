# 05: 保存到磁盘与输出策略

**What to build:** 截图后除了进剪贴板，还能按 `⌘S` 落到磁盘。文件保存在用户配置的位置，按可配置的命名模板命名，格式与质量可选。默认行为是"剪贴板优先"：不保存也能直接用；需要归档时一键落盘。

**Blocked by:** 03

**Status:** 已实现，待人工验收（2026-10-01）

格式、目录、模板的设置界面在 ticket 15。本条先把 `⌘S` 落盘、命名模板和默认值接上：默认桌面、PNG、质量 0.9、模板 `Marquee {date} at {time} {index}`。`⏎` 仍然只进剪贴板。

## 设计约束（已定）

- **默认不自动落盘**（PRD B6「剪贴板优先工作流」+ F9「保存后行为收敛为一个偏好项」）：
  截完就进剪贴板，只有用户按 `⌘S` 或显式开了 F9 那个偏好项才写磁盘。
  「截图后自动保存到某个位置」**不是**默认行为 —— 需要时由 F9 偏好项提供，默认关闭。
  用户 2026-09-30 问过"截取的内容自动保存在哪"，本条就是那个 ticket；若希望改默认行为，在此处确认后调整。
- 默认保存位置：桌面；可在偏好设置中修改
- 支持格式：PNG（默认）/ JPEG / HEIC；JPEG/HEIC 的质量可调
- 命名模板支持：日期、时间、序号、来源应用名、窗口标题
- 编码走 ImageIO（`CGImageDestination`），不要自造 PNG 编码
- 落盘目录不存在时自动创建；写入失败要给明确错误而不是静默吞掉

## Acceptance criteria

- [x] 命名模板渲染有单元测试，覆盖：日期/时间替换、序号补零、非法字符过滤、超长窗口标题截断
- [x] 落盘：目录不存在会创建；同名不覆盖、序号递增；不可写时返回说明
- [x] JPEG 降质量后体积下降，解码像素尺寸不变
- [x] 落盘失败时剪贴板里的 PNG 仍在
