# 19: 选区几何编辑与边缘吸附

**What to build:** 把「拖出选区」从"只能重画一次"补齐到可以精细调整：
拖控制点改大小、拖框内移动整框、`⇧` 锁比例、点尺寸数字直接输入精确尺寸；
以及拖拽时的边缘吸附（吸附到窗口边界 / 屏幕边缘）。

**Blocked by:** 无（独立于 20–23，可并行或后置）

**Status:** ready-for-agent

## 为什么会有这一票

用户的原话："正常应该有对拖拽区域的大小编辑功能，我看到当前项目的 PRD 还没有。"

核对下来**一半对**：

| PRD 里写的 | 实现状态 |
| --- | --- |
| B3「实时显示尺寸 pt & px + 坐标」 | ✅ 有 |
| B3「方向键 ±1px / `⇧`±10px 微调」 | ✅ 有 |
| B3「**`⇧` 锁定正方形/比例**」 | ❌ **写了但没实现**（现在 `⇧` 只改微调步长） |
| F6「**智能吸附**：边缘吸附窗口 / 屏幕边缘」 | ❌ **未实现** |
| 旧版能力表「比例锁定」 | ❌ 同上 |
| **拖控制点改大小 / 拖框移动 / 输入精确尺寸** | ❌ **PRD 里也确实没有** —— 用户指的正是这个 |

所以本票既补 PRD 已写未做的（`⇧` 锁比例、边缘吸附），也补 PRD 漏掉的（控制点、输入尺寸）。

## 设计约束（已定）

- **落点之后再点选区空白处，仍然保持"空操作"**（现状）。
  理由：加了拖动之后，误触空白处如果清掉选区，用户会丢掉刚调好的框。
  要重框就在框外按住拉一个新的。
- 控制点命中半径与编辑器的 `AnnotationHandle` 保持同一量级（约 6 pt），
  手感一致。
- 最小框 **8 px**（沿用现有"框 <8 像素视为误操作"的阈值）。
- `⇧` 的两种用法**不冲突**，可以共存：
  - 拖角时按住 `⇧` → 锁定当前宽高比（从空开始拉 = 正方形）
  - 按住 `⇧` + 方向键 → ±10px 微调（现状）
- 几何全部抽成 **Core 的纯函数**（`SelectionGeometry`），可脱机单测：
  控制点命中、对边固定缩放、锁比例、边缘吸附候选。

## Acceptance criteria

- [ ] 落点后选区显示 8 个控制点（四角 + 四边中点）
- [ ] 拖控制点改大小，**对边保持不动**；拖到最小尺寸时停住不翻转
- [ ] 拖选区内部 = 移动整框（尺寸不变）
- [ ] 拖角时按 `⇧` 锁比例；从空开始拉时按 `⇧` 拉出正方形
- [ ] 点读数里的尺寸数字 → 变成输入框，输入后回车应用（`Esc` 放弃）
- [ ] 拖拽时吸附到窗口边界 / 屏幕边缘，阈值约 6 pt；**吸附是可感知但不粘滞的**
      （继续拖能离开吸附位，不要"吸住不放"）
- [ ] 上述几何全部有 Core 单测 + **变异测试**验证断言非空跑
- [ ] 光标形状跟随控制点（对角 / 水平 / 垂直 resize）

## 风险

- 控制点拖拽与**标注工具**（21/22 之后）会抢鼠标事件：
  落点后点击是先判"命中控制点"还是先判"命中标注对象"？
  **建议顺序：控制点 → 标注对象 → 空白**（控制点最"尖"，优先）。
  这条要写进代码注释，否则以后有人调换顺序就会出怪现象。
