# 03: 选区覆盖层 —— 拖拽选区并截取

**What to build:** 按下快捷键后，屏幕暗下来，鼠标变成十字。拖拽划出一个矩形，框内保持原亮度、框外变暗，拖动过程中实时显示尺寸（点与像素两种单位）与坐标；松开鼠标，选区内容立刻进入剪贴板。`Esc` 在任何阶段都能干净退出，不留残影、不残留窗口。多显示器时每个屏幕都要出现蒙层，跨屏拖拽要正确。全屏应用之上也能用。

**Blocked by:** 02

**Status:** ready-for-agent

## 设计约束（已定）

- 覆盖层用 **AppKit 逐屏 `NSPanel`**，不用 SwiftUI 承载这一层
- **绝对不要**把整屏截图铺到窗口上当底图（会产生色彩偏移、HDR 色调映射错误和"截屏套娃"）。只画：变暗蒙层 + 选区镂空 + 高亮描边
- 采集时必须排除本进程自己的窗口，确保输出里没有蒙层
- 覆盖层出现与清单查询并行，不要串行等待

## Acceptance criteria

- [ ] 按下快捷键后蒙层在当前 Space 出现，**不会把用户切到应用所在的另一个 Space**
- [ ] 拖拽中实时显示选区宽高（pt 与 px）与左上角坐标；`⇧` 拖拽时锁定为正方形
- [ ] `Esc` 在出现蒙层后、拖拽中、松开前三种状态下都能干净退出，屏幕无残影、无多屏残留
- [ ] 松开后剪贴板得到选区图，像素尺寸 = 选区点尺寸 × 该屏 backing scale（Retina 下 2x）
- [ ] 输出图中**不含**蒙层与任何 Marquee 自己的窗口
- [ ] 双屏（或外接屏）下两个屏都出现蒙层；跨屏拖拽选区正确，混合 scale 时不出现尺寸错乱
- [ ] 原生全屏应用之上可以正常选区截取
- [ ] 方向键可对选区做 ±1 px 微调（`⇧` + 方向键 ±10 px）
- [ ] 选区几何计算（全局点坐标 ↔ 每屏像素）有单元测试，覆盖混合 DPI 场景
