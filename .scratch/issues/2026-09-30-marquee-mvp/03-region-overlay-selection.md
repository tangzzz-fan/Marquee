# 03: 选区覆盖层 —— 拖拽选区并截取

**What to build:** 按下快捷键后，屏幕暗下来，鼠标变成十字。拖拽划出一个矩形，框内保持原亮度、框外变暗，拖动过程中实时显示尺寸（点与像素两种单位）与坐标；松开鼠标，选区内容立刻进入剪贴板。`Esc` 在任何阶段都能干净退出，不留残影、不残留窗口。多显示器时每个屏幕都要出现蒙层，跨屏拖拽要正确。全屏应用之上也能用。

**Blocked by:** 02

**Status:** 已实现，待人工验收（2026-09-30）

## ⚠️ 本条会改变「截屏」入口的语义（用户 2026-09-30 指出）

当前（ticket 02 结束时）点菜单「截屏」或按 `⌃Q` 是**直接全屏截图**，那是 ticket 02 刻意做窄的
端到端探路形态，**不是最终交互**。

本条落地后，入口统一指向覆盖层。**已按 PRD B4 定案**（用户 2026-09-30 确认"可以"）：
不新增独立的"直接全屏"菜单项，整屏是覆盖层内的一种选择。

覆盖层内的完整键位（实现后回填，用户已认可的方向）：

| 操作 | 行为 |
| --- | --- |
| 拖拽 | 划出选区；`⇧` 锁定正方形 |
| 松开鼠标 | 立即采集选区 → 剪贴板 |
| 方向键 | 平移选区 ±1 **像素**（`⇧`±10 像素，按该屏 backing scale 换算成点） |
| `⏎` | 有选区＝提交；**无选区＝整屏** |
| **双击** | 整屏 |
| `Esc` | 取消并干净退出（任何阶段） |

## 实现要点（落地后回填）

| 关注点 | 落点 |
| --- | --- |
| 状态机 | `MarqueeCore.SelectionSession`（纯值类型，20 个单测） |
| 坐标换算 | `MarqueeCore.ScreenCoordinateConversion`。Cocoa（原点左下）↔ Quartz（原点左上），**矩形按边翻** |
| 跨屏布局 | `MarqueeCore.SelectionLayout`（逐屏取交集 + 按边算落位，混合 DPI 取最大 scale） |
| 拼接 | `MarqueeCore.ImageCompositing`（单切片铺满走直通；多片 `CGContext` 绘制**必须翻 y**） |
| 流程 | `MarqueeCore.RegionCaptureFlow`（权限门共用 `CaptureGateRunner`） |
| 采集 | `MarqueeCapture.ScreenCaptureKitCapturer.captureRegion`（`sourceRect` = 该屏内容空间的**点**坐标） |
| 窗口层 | `MarqueeOverlay.SelectionOverlayController` / `SelectionOverlayPanel` / `SelectionOverlayView` |
| 开发冒烟 | `Marquee -marqueeSmokeOverlay` 启动即弹覆盖层、1.5 秒后退出（验证创建/绘制/拆解不崩） |

## 设计约束（已定）

- 覆盖层用 **AppKit 逐屏 `NSPanel`**，不用 SwiftUI 承载这一层
- **绝对不要**把整屏截图铺到窗口上当底图（会产生色彩偏移、HDR 色调映射错误和"截屏套娃"）。只画：变暗蒙层 + 选区镂空 + 高亮描边
- 采集时必须排除本进程自己的窗口，确保输出里没有蒙层
- 覆盖层出现与清单查询并行，不要串行等待

## Acceptance criteria

### 自动化已验证

- [x] 选区几何计算（全局点坐标 ↔ 每屏像素）有单元测试，覆盖混合 DPI 场景
      —— `SelectionLayoutTests`：单屏 2x / 1x、超出屏裁边、1x+2x 跨屏、按边算落位**严丝合缝**（相邻切片边界相等）、屏外返回 nil
- [x] 拖拽归一化（四方向）、⇧ 锁正方形（横/纵/左上三个方向）、⇧ 立即生效不等鼠标移动
- [x] 零面积与亚点选区不成立（且**阈值在吸附之前判**，否则 0.5 点会被吸成 1 点）
- [x] 方向键微调不吸附整点（2x 屏 ±1 像素 = 0.5 点，吸附会把这一步吃掉）
- [x] Cocoa ↔ Quartz 换算对合，且**矩形按边翻**（专门有一条断言钉住"只翻原点"的错误写法）
- [x] 拼接装置自检：横向/纵向拼接的像素落位正确，**y 翻转写错会立刻转红**；单切片铺满走直通
- [x] 采集流程：单屏一次取片、跨屏逐屏取片且每片拿到的是"该屏与选区的交集"、权限没过不采集、屏外失败
- [x] 全量 `./scripts/test.sh` **100 tests / 20 suites 全绿**；`-marqueeSmokeOverlay` 冒烟不崩
