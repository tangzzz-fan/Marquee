# 21: 覆盖层内直接标注（工具条 + 形状类工具）

**What to build:** 把浮动工具栏从"三个动作按钮"改成**真正的标注工具条**，
并在覆盖层里**就地画标注** —— 不再有"点「编辑」跳进另一个窗口"这一步。
本票做**形状类四个工具**（矩形 / 椭圆 / 箭头 / 画笔）+ 色板 + 线宽 + 撤销重做 + 保存/取消/完成。

**Blocked by:** 20

**Status:** ✅ 已实现（2026-10-01），文字 / 马赛克 / 模糊见 22

## 用户的原始要求

> 我的意思是实现我前面给你截图提供的一个工具栏 类似的效果，
> 不是使用一个编辑按钮跳转的方案

（ticket 20 的「编辑」按钮是过渡入口，本票把它删掉了。）

## 关键设计一：绘制与导出**共用同一套 CG 代码**

- 导出走 `AnnotationRasterizer`（CoreGraphics）
- 覆盖层也是 CoreGraphics（`SelectionOverlayView.draw(_:)` 用 `NSGraphicsContext.cgContext`）

所以抽出 **`MarqueeCore.AnnotationDrawing`**，两边都调它：
覆盖层把 CTM 平移 + 翻一次 y（AppKit 是左下原点 y 向上，标注约定是左上原点 y 向下），
之后就是同一份绘制。于是"覆盖层里看到的"与"导出的"**天然一致**。

> ❌ **反面做法**：覆盖层用 `NSBezierPath` 自己再画一遍。描边宽度、颜色空间、文字基线
> 都会与导出漂移，而且每次只在**某些图上**看得出来（纯色测试图、对称图都是盲的 —— PITFALLS 40）。

## 关键设计二：坐标用**点**，不是像素

标注在覆盖层里存"**选区局部点**"（原点 = 选区左上角，y 向下），
到像素的换算只在**栅格化那一刻**做一次（`InlineAnnotations.scaled(toPixelSize:)`）。

- 画的时候 1 点 = 1 屏幕点，线宽按"看起来多粗"定，符合直觉
- 存像素就得在每次鼠标移动时反向换算；换屏 / 改分辨率后已有标注还要重算
- 倍率由采集流程定（它才知道最终的输出像素尺寸，跨屏选区时不是逐屏一致的）

> ⚠️ **线宽必须跟位置一起放大**。只缩 `frame`/`path` 的话，Retina 上导出的线条会细成
> 屏幕上的一半 —— 表现是"导出把线变细了"，很容易被当成显示问题。

## 关键设计三：会话在 Core，纯逻辑

`OverlayAnnotationSession`：工具选择（**再点一次取消**）、落笔/更新/收笔、最小尺寸丢弃、
撤销重做栈。放在 `MarqueeOverlay` 里就只能靠人手点 ——
而"一次误点留下一个 1×1 的脏点"恰恰是最不容易手工复现的。

## 逐项对照

| 需求 | 落点 |
| --- | --- |
| 工具条（工具 + 色板 + 线宽 + 撤销重做 + 保存/取消/完成） | `OverlayToolbar`（Core，单一 `layout()`） |
| 色板与线宽与编辑器一致 | `AnnotationPalette`（Core 共享，编辑器也改用它） |
| 画矩形 / 椭圆 / 箭头 / 画笔 | `OverlayAnnotationSession` + `AnnotationDrawing` |
| 撤销 / 重做 | 会话内的栈，工具条上按 `canUndo`/`canRedo` 置灰 |
| 完成 → 图里带标注 | `CaptureOutput.finish(inline:)` → `AnnotationRasterizer` |
| `Esc` 分级退出 | 草稿 → 工具 → 整次取消（见下） |

## `Esc` 分三级，不会一步把整次截图丢掉

1. 画到一半 → 丢掉这一笔
2. 选了工具 → 取消工具（回到"调整选区"）
3. 其它 → 取消整次截图

少了前两级的话，用户画了五个箭头想退出画标注模式，一下 `Esc` 全部作废。

## 刻意的决定

- **一次误点不留脏点**：一笔至少 3 点才算数（`minimumExtent`）。留下的往往是一个 1×1 的点，
  得先放大才找得到，却会一直出现在导出图里。
- **反向拖拽用 `union` 而不是自己算 min/max**：后者会得到负尺寸的框，
  描边在有的路径上画不出来 —— 表现是"往回拖就什么都没有"。
- **落笔在选区外什么都不做**：不偷偷重画选区，也不画到选区外（会被裁掉，像"工具坏了"）。
- **有就地标注时窗口截图强制去掉阴影**：带阴影的窗口图比窗口矩形大一圈，
  而标注坐标是相对窗口矩形算的 —— 差这一圈所有标注整体偏移，
  且偏移量随阴影大小变（浅色背景下阴影大）。宁可这张图没有阴影。
- **栅格化失败 → 整次截图失败**，绝不"回退成原图"：标注里可能有打码，
  静默交出未处理的图＝把用户以为遮住的内容原样发出去。
- **双击在选了工具时被挡掉**：第一下已经算一笔了，第二下被吃掉会让人以为"手快了就丢笔"。

## 风险 / 未做

- **文字 / 马赛克 / 模糊**：不在本票（见 22）。`AnnotationDrawing` 已经支持这三类，
  覆盖层缺的是"输入框"与"底图像素"两样前提。
- **性能**：每次 `draw` 都会重画全部标注。个位数无碍；几十个时需要按脏区重绘。
  本票不做优化。
- **选中 / 移动已有标注**：本票只能撤销，不能改了再改（见 22）。
