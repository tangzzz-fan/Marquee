# 22: 覆盖层内补齐标注工具与参数

**What to build:** 把 21 打通的链路补齐到与编辑器同等的工具集：
椭圆 / 箭头 / 画笔 / 文字 / 序号 / 马赛克 / 模糊 / 裁切，
加上颜色、线宽 / 字号 / 打码强度、撤销重做。

**Blocked by:** 21

**Status:** ready-for-agent

## 设计约束（已定）

- **工具栏仍 ≤ 9 个工具**（PRD 3.1）：选择、矩形、椭圆、箭头、画笔、文字、马赛克、模糊、裁切。
  **序号依旧是文字工具的一个预设**，不占独立工具位（与编辑器完全一致）。
- 参数控件按**当前上下文**切换：选中文字改字号、选中打码改强度、其余改线宽 ——
  与编辑器里 `sizeControls` 的做法一致，**不要**在覆盖层里再摆一排新控件。
- 一切几何与文字继续走 Core（`AnnotationGeometry` / `AnnotationText`），
  与导出共用绘制（21 已建立）。

## ⚠️ 需要实测的一条：覆盖层里的文字输入

覆盖层是 `.nonactivatingPanel` 且窗口层级很高（`.screenSaver`）。
**`NSTextField` 在这个环境里能不能正常收键盘，没有验证过** ——
而键盘恰恰是这个项目已经踩过坑的地方（`PITFALLS` 56：`⏎` 曾经完全收不到）。

先做一次最小验证：
- 在覆盖层上放一个 `NSTextField`，看能否聚焦、输入、回车提交。
- **若不可行**：降级为"落点后弹一个独立的小输入条"（用一个普通的
  `NSPanel` 承载，或者在覆盖层里用一个自绘的输入框 + 自己收 keyDown）。

这条**不要靠猜**：先跑最小验证，再决定形态。

## Acceptance criteria

- [ ] 八类标注都能在覆盖层里画出来，且**导出结果与覆盖层所见一致**
- [ ] 颜色 / 线宽 / 字号 / 打码强度都能改，且作用于当前选中对象
- [ ] 马赛克与模糊走 CoreImage（与导出同一条路径，`RedactionFilter`）
- [ ] 裁切：拖框、回车应用、Esc 取消（**注意 Esc 此时是"退出裁切"而不是"取消整次截图"**）
- [ ] 文字输入可用（或按上面的降级方案实现，并在 ticket 里注明最终形态）
- [ ] 撤销 / 重做覆盖全部工具
- [ ] 选中与移动：点击选中对象、拖动移动、控制点改大小（与编辑器的命中测试同一套
      `AnnotationDocument.hitTest`）

## 依赖与风险

- 文字输入是本票唯一的未知项，**先验证再实现**。
- 覆盖层的绘制量随标注数增长，若出现掉帧，按脏区重绘处理（21 已留注释）。
