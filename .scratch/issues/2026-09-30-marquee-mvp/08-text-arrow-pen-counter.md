# 08: 文字 / 箭头 / 画笔 / 序号标注

**What to build:** 在已有对象模型上补齐其余标注工具：文字（可直接输入与二次编辑）、箭头（指向性明确）、自由画笔、以及自动递增的序号标记。四种新标注与矩形一样，落地后都**可以被再次选中修改**。

序号标记不占独立工具位，收敛为文字工具的一个预设（`1.` `2.` 自增），以符合工具栏 ≤ 9 个工具的约束。

**Blocked by:** 07

**Status:** ready-for-agent

## 设计约束（已定）

- 四类新标注必须复用 07 建好的对象模型与撤销栈，不得各自造一套
- 序号标记是文字标注的一种预设，不新增工具按钮
- 文字以矢量方式保存（字符串 + 字体 + 字号 + 颜色），导出时才栅格化，保证可反复编辑
- 画笔用折线点序列保存，支持后续改色改粗细

## Acceptance criteria

- [ ] 可放置文字标注并直接输入；已放置的文字双击可再次编辑内容
- [ ] 可画箭头，箭头指向与拖拽方向一致，线宽可调
- [ ] 可自由画笔绘制曲线，绘制中跟手无延迟
- [ ] 连续放置序号标记时自动递增，可手动改起始值
- [ ] 以上四类标注均可被选中、移动、删除、改色、改线宽
- [ ] 导出后四类标注渲染正确（箭头头部、文字基线、画笔笔画无裁切）
- [ ] `⌘Z` 对每一类标注的创建与修改都正确撤销
- [ ] 文字与画笔的几何/样式序列化有单元测试（存-取-再渲染一致）
