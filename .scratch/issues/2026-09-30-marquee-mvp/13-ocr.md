# 13: OCR 文字识别

**What to build:** 截图里的文字能直接取出来：截完图点一下 OCR，识别出的文本按行展示，可以整段复制，也可以只划取需要的部分复制。识别完全在本地完成，不联网。

**Blocked by:** 07

**Status:** 🟡 已实现（2026-10-01），识别效果与首次响应时间待人工验收

## 已提前验证的结论（直接用，不要重新试）

- 用系统 Vision（`VNRecognizeTextRequest`），本地运行，不需要任何模型下载
- **首次调用约 25 秒**（模型未缓存），模型缓存后冷启动 177 ms、稳态 p50 60 ms（900×260 px，accurate，中英双语）
- 因此**必须在应用启动时后台预热**（对一张 1×1 空图跑一次请求），否则用户第一次点 OCR 会以为应用卡死

## 实现记录（2026-10-01）

### 入口是「动作」不是「工具」

PRD 3.1 把编辑器工具栏的 9 个位置明确列满了（选择、裁切、矩形、椭圆、箭头、画笔、文字、马赛克、序号），
OCR **不在其中**。而且它本来也不改文档、只产出一份文本 —— 所以它放在工具栏右侧的**动作区**
（缩放控件旁边），不占工具位。

### 代码落点

| 关注点 | 落在哪 | 为什么 |
| --- | --- | --- |
| 结果模型（行 / 整段 / 字数） | `MarqueeCore.TextRecognitionResult` | 纯值类型，拼接规则可测 |
| Vision 包围盒的坐标换算 | `MarqueeCore.RecognizedTextLine.frame(fromNormalized:imageSize:)` | 纯几何；**放 Core 才有测试钉着**（见下） |
| 状态机（idle/running/ready/empty/failed） | `MarqueeCore.TextRecognitionService` | 界面只看它；空结果与失败要分开说 |
| 启动预热 | `MarqueeCore.TextRecognitionPreheater` | 幂等、失败不致命，逻辑可测 |
| 真实识别 | `MarqueeCapture.VisionTextRecognizer` | Vision 是系统 API |
| 面板与按钮 | `MarqueeEditor.AnnotationEditorWindow` | 只画状态，不做判断 |

### 几个刻意的决定

- **`VNImageRequestHandler.perform` 是同步阻塞的**，而调用方在 MainActor 上 ——
  整趟扔进 `Task.detached`，否则"识别中…"的反馈根本转不起来。
- **预热图不用 1×1**（PRD 原文的建议）：太小会被 Vision 当无效请求直接拒掉，
  那样预热就变成"什么都没热"，而且要等用户第一次点才发现。改用 64×64 —— 成本在模型加载，不在像素多少。
- **包围盒的 y 必须翻**：Vision 是「归一化 + 原点左下」，标注模型是「像素 + 原点左上」。
  面板眼下只显示文本、不画框，所以翻错了**既不报错也看不见**，要等以后做"点某行高亮原图上那块"才暴露。
  因此把换算放进 Core 并留了测试。
- **面板用 `Text` + `textSelection`**，不用可编辑控件：用户要的是"能划、能 ⌘C"，不需要改。
- **状态文案必须存在**（识别中 / 没有识别到文字 / 失败原因）—— 留白会让人以为是功能坏了。

## Acceptance criteria

- [x] 截完图可一键 OCR，识别结果按行展示，文本可选中（`.textSelection(.enabled)`，系统选择即"部分复制"）
- [x] 整段复制与部分选择复制都可用（「全部复制」按钮 + 系统文本选择）
- [ ] 中文与英文混排内容都能正确识别 —— 语言列表已按 `["zh-Hans", "en-US"]` 给到 Vision，
      **实际识别质量待人工验**（我在脱机环境里跑不了真实 Vision）
- [ ] **应用启动后首次点击 OCR 响应时间 < 500 ms**（预热已接线，`-marqueeDiagnostics` 会显示预热状态；
      **待人工计时**）
- [x] 识别过程不阻塞界面；大图识别时有进度或等待反馈（按钮变「识别中…」并禁用，面板显示状态行）
- [x] 识别失败或无文字时给出明确提示，不显示空白让人困惑
- [x] 预热逻辑有测试：断言预热在应用启动后完成、且失败不影响主流程

## 人工验收补充

1. 启动应用后**先跑一次** `Marquee -marqueeDiagnostics`：`OCR 预热` 应显示「已完成」（首次启动可能要等一会儿才变）。
2. 截一张**中英混排**的图 → 点「识别文字」：面板应显示行数 / 字数 / **耗时**。
   耗时是关键证据 —— 若显示几十秒，说明预热没生效（或那次正好是首次）。
3. 面板里用鼠标划选几个词 → `⌘C` → 粘到别处，应当只有选中的部分。
4. 点「全部复制」→ 粘出来的应当是完整多行文本（**行与行之间是换行**，不是粘成一坨）。
5. 截一张**没有文字**的图（纯色桌面）→ 点识别：应显示「这张图里没有识别到文字」，而不是空白面板。
